# Hugging Face Cookbook submission

On November 25, 2026 (Korea time), Codex submitted an original English CPU notebook, *Measure the memory used by a decoder’s KV cache*, on behalf of the textbook maintainer, Seongeun So. Hugging Face's Open-Source AI Cookbook accepts standalone educational notebooks through GitHub. The submission identifies the authoring assistance, credits the textbook's KV cache lesson and adds the notebook to the English index and table of contents. The PR was open when verified. Publication in the Cookbook awaits the maintainers' review. [Submission #393](https://github.com/huggingface/cookbook/pull/393) · [Submitted notebook](https://github.com/sungeuns/cookbook/blob/4640bbf5e5275380cf6a665e049378db30ae6d29/notebooks/en/measure_kv_cache_payload.ipynb) · [Contribution guidelines](https://github.com/huggingface/cookbook#contributing-to-the-cookbook)

The notebook ran in a fresh Python 3.12 CPU kernel with PyTorch 2.15.0 and Transformers 5.24.1. With two padded prompts, its SmolLM2-135M key/value tensors occupied 1,013,760 bytes after the first forward pass and 1,382,400 bytes after four further positions per request. Each cached next-token logit vector was compared with a full recomputation. The submitted commit is `4640bbf5e5275380cf6a665e049378db30ae6d29`.
