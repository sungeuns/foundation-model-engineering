# 17.6 Commercial and Open-weight Model Benchmarks

A model release changes more than a leaderboard. It can change access, licensing, prompt encoding, pricing, output budgets, or the revision behind a stable API alias. Evaluate those contracts before treating a familiar name as a drop-in replacement.

**As of 2026-10-18.** This is a dated historical snapshot, not a live leaderboard. The sources below were rechecked for this pass and **must be reverified** before a later publication or procurement. The October 13 snapshot has been superseded here; the selected October milestones include broader access, weight releases, and checkpoint updates rather than pretending every date is an original announcement.

## 1. Read the Evaluated System, Not Only the Model Name

The index values below use Artificial Analysis Intelligence Index **v4.3.2**, a defined set of ten evaluations [[1]](#ref-1). The reported effort/fallback profile is part of each result. Models with different effort settings or provider routing are **not equal-compute or controlled weights-only comparisons**. Use the table to identify systems for a private evaluation at matched task, tool, latency, and budget constraints.

Where the source does not state a numeric effort, the table says so. Do not infer one. The hosted Step 5 profile predates the new public weights; the September DeepSeek profile is not a verified evaluation of the October 17 revision. Unknown revision equivalence is a reason to run a new test, not to copy a score.

## 3. What Changed Since the Previous Pass

### Public weights are a separate milestone

Beam moved from the October 5 announcement to released weights on October 16 [[26]](#ref-26). Its card describes BF16, FP8, and NVFP4 artifacts, a modified Harmony chat format, and a still-pending full technical report [[27]](#ref-27). Do not treat an NVFP4 file's packed tensor count as a different model architecture.

Muse Spark Open is a released, gated checkpoint under the Muse Model License. The card distinguishes its additional safety post-training from the hosted Spark lineage [[33]](#ref-33). “Open-weight” does not imply an Apache license, unrestricted download, or complete data disclosure. Step 5 Preview now has public BF16 and lower-precision artifacts under its own license; its **Preview** name does not mean the weights are still only promised [[39]](#ref-39). Review the actual license and exact artifact revision before deployment.

### Hosted models and broader access are different again

Muse Wonder is available through Meta's API and Muse Code; Wonder Full is available through Muse Code subscriptions [[29]](#ref-29). Their announcement does not disclose parameter counts or a full training recipe. Do not transfer the API model's token price to the subscription-only variant.

Gemini 4 Argon's broader API access began October 13. The current model contract specifies a unified input/output window and separate synchronous versus long-decode output limits [[17]](#ref-17). Standard paid rates are \$2 input/\$10 output per million tokens through **2026-11-30**, then \$4/\$20 from **2026-12-01** [[18]](#ref-18). Model the expiry explicitly; neither a promotional rate nor the largest output allowance is a permanent universal contract.

### A stable alias can change the model

The October 17 DeepSeek changelog states that `deepseek-flash` now points to V4.1 Flash 1017 without an API-call or price change [[42]](#ref-42). Its model card reports gains with named harnesses and supplies protocol-aware encoding rather than a Jinja chat template [[41]](#ref-41). Those are provider results, not new AA measurements. Pin checkpoint/encoder revisions, preserve tool and image encoding, and compare the complete system before canarying the updated alias.

### Smaller storage is not a deployment guarantee

Nemotron 3.5 Super VL and Bolt disclose hybrid state-space/attention/MoE vision-language designs. Bolt's IQ2 QAT and 24GB packed-model target require compatible kernels and separate state/workspace accounting [[37]](#ref-37). The model name cannot establish the memory available for long context or concurrent requests. Section 13.5 separates nominal bit width from measured system capacity.

Mistral Large 4 remains a public API preview with a later-October weight plan in its launch post [[24]](#ref-24). Claude pricing remains configuration-sensitive: the overview qualifies Haiku rates with “from” [[43]](#ref-43). Preserve such qualifiers rather than filling gaps with minimum prices or anticipated releases.

## 4. Explore Profiles Without Manufacturing Missing Data

The chart plots only rows with values for the selected metric and axis. Its selection list is alphabetical; it is not a universal quality ranking. For token prices, the illustrative proxy is $(3p_{in}+p_{out})/4$, where $p_{in}$ and $p_{out}$ are uncached standard input/output prices per million tokens. It is a hypothetical 3:1 mix, excluding cache writes/hits, tools, image/audio charges, long-context tiers, and reasoning length. Only documented standard rates are included.

The context metric shows a declared limit, not measured long-context reasoning quality. Source-specific input/output semantics still apply. No speed curve is fabricated from incomparable providers or missing measurements.

## 5. A Production Evaluation Gate

Evaluate candidate profiles on the same private tasks with pinned scaffold, tools, effort, context/output budget, retries, and grader. Add supported-language, format, authorization, safety, retention, latency-tail, cost-per-success, and error-rate slices. Test local quantized checkpoints independently of hosted results. Use paired uncertainty or a justified sample size, and block release on critical-slice failure even if the average improves.

Keep the model, tokenizer or encoding toolkit, template, runtime, tool schema, generation configuration, and policy hashes as one artifact bundle. Canary a replacement under bounded permissions, keep a known-good route, and rehearse rollback—including cached state and pending tool effects. A new release is an evaluation trigger, not a deployment instruction.

<details>
<summary>Quiz 2: Why is Step 5 Preview now described as released/open-weight?</summary>
*Usable weight artifacts are public. The product name does not determine release state; the actual artifacts and license do.*
</details>

<details>
<summary>Quiz 3: Why does Wonder Full's missing task cost not mean it is the cheapest profile?</summary>
*Its subscription access does not provide a public API task-price observation. Missing cost cannot be substituted with zero or the API sibling's rate.*
</details>

<details>
<summary>Quiz 4: Why must Gemini's introductory rate have an expiry in a cost model?</summary>
*The documented standard prices change after November 30. A workload crossing that boundary can have a different cost without any model-name change.*
</details>

<details>
<summary>Quiz 5: Why do public weights and a hosted benchmark not establish local production readiness?</summary>
*The local revision, quantization, encoding, kernels, state layout, and scaffold may differ. Validate the complete artifact bundle under the intended workload and release gates.*
</details>
