# 20.3 Linear Attention

A decoder receives three values in the order 2, 8, 20. If the first and third have the same key, can it still retrieve the first value on its own? That depends on what the layer kept when it read the third token. In additive linear attention, you can follow the write, reproduce the readout, and count the bytes in the state.

---

## 1. The Core Idea

For input queries $Q$, keys $K$, values $V$ and key width $d$, dense softmax attention computes a score for each visible token pair. Fused kernels can evaluate the following expression without storing its complete score matrix.

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d}}\right)V
$$

Choose a kernel that scores each pair by the dot product of two feature vectors, $\phi(q)^T\phi(k)$. Its unnormalized numerator can be reassociated as

$$
\phi(Q)\left(\phi(K)^T V\right)
$$

For a decoder, the limits of the two sums determine which tokens a query can see. At position $t$, include only the prefix through $t$.

$$ S_t=\sum_{i=1}^t \phi(k_i)v_i^T,\qquad z_t=\sum_{i=1}^t \phi(k_i),\qquad y_t^T=\frac{\phi(q_t)^T S_t}{\phi(q_t)^T z_t}. $$

$q_i$, $k_i$ and $v_i$ are the query, key and value at position $i$. A nonnegative feature map $\phi$ has width $m$. Each new token adds an outer product to the $m\times d_v$ matrix $S_t$ and its key features to the length-$m$ vector $z_t$. The denominator is the total kernel weight visible to this query. This equation assumes positive total weight. Implementations need a policy for zero or very small denominators. [[1]](#ref-1)

## 2. Why the Idea Is Attractive

For fixed feature and value widths, one more decode step writes $m d_v$ entries and reads a state of the same shape, independent of prefix length. The connection between recurrence and structured matrix products also appears in state space duality. [[3]](#ref-3) By comparison, a dense attention head retains a key and a value per visible position and can score each key separately. A fixed-size matrix can still take more space at short lengths. The [memory calculator](#context-state-memory) shows where that changes.

## 3. Why Earlier Variants Struggled

Suppose the values 2 and 20 both have key features $(1,0)$, and the value 8 has features $(0,1)$. The final state holds sums $(22,8)$ and counts $(2,1)$. A query with features $(1,0)$ reads $22/2=11$. Swapping 2 and 20 leaves this final state unchanged. A reader given only the state cannot recover which one arrived first. Positional features, context-dependent keys and other update rules can change that conclusion.

## 4. What Modern Work Tries to Improve

### An Emerging Hybrid Pattern

Yang et al. tested stacking delta-rule layers with sliding-window or global attention. Their retrieval experiments give a reason to check exact recall separately from average language-model loss. Dense layers can retain individual earlier keys. Recurrent layers carry their own fixed-size state. A serving system for a hybrid model must budget for both. [[2]](#ref-2)

### Additive memory versus the delta rule

A simple gated write decays state and adds new information. The delta rule instead makes a **state-dependent correction**, subtracting the prediction already stored along the current key. [[2]](#ref-2)

$$ S_t=(I-\beta_t k_tk_t^T)S_{t-1}+\beta_t k_tv_t^T. $$

Here $S_t\in\mathbb R^{d_k\times d_v}$, $k_t\in\mathbb R^{d_k}$, $v_t\in\mathbb R^{d_v}$, and $\beta_t$ sets write strength. With unit-norm keys, $k_tk_t^T$ projects onto the key direction. The correction can act along one key direction while preserving state in perpendicular directions. Gated DeltaNet also adds forgetting; check its normalization and gate ordering in the actual implementation. [[4]](#ref-4)

## 5. Educational PyTorch Example

<a id="causal-linear-scan"></a>

### Change the last value and predict the first two outputs

The first query reads only the value 2. The next query, with features $(1,1)$, gives both visible keys weight 1 and reads $(2+8)/2=5$. Predict what happens to those outputs when the third value changes from 20 to 100. Run the block on CPU with Python 3.10+ and PyTorch.

**Scope of the example.** One head processes one unpadded sequence of float32 features. The query and key features are supplied directly. The loop exposes the state after each write. A batched decoder would also need projections, masks, per-request state and a kernel suited to its hardware.

```python
import torch

# Rows already contain the query and key features for one attention head.
queries = torch.tensor([[1., 0.], [1., 1.], [1., 0.]])
keys = torch.tensor([[1., 0.], [0., 1.], [1., 0.]])
values = torch.tensor([[2.], [8.], [20.]])

def scan(queries, keys, values, state=None):
    if state is None:
        memory = values.new_zeros(keys.shape[1], values.shape[1])
        counts = keys.new_zeros(keys.shape[1])
    else:
        memory, counts = state

    outputs = []
    for query, key, value in zip(queries, keys, values, strict=True):
        memory = memory + torch.outer(key, value)
        counts = counts + key
        normalizer = query @ counts
        if normalizer <= 0:
            raise ValueError("query has no overlap with the visible keys")
        outputs.append((query @ memory) / normalizer)
    return torch.stack(outputs), (memory, counts)

stream, _ = scan(queries, keys, values)
weights = (queries @ keys.T).tril()
reference = (weights @ values) / weights.sum(dim=1, keepdim=True)
torch.testing.assert_close(stream, reference)
print(stream.flatten().tolist())

_, prefix_state = scan(queries[:2], keys[:2], values[:2])
suffix, _ = scan(queries[2:], keys[2:], values[2:], prefix_state)
torch.testing.assert_close(suffix, stream[2:])

changed_values = values.clone()
changed_values[2] = 100.
changed, _ = scan(queries, keys, changed_values)
torch.testing.assert_close(changed[:2], stream[:2])
print(changed.flatten().tolist())
```

The two runs print `[2.0, 5.0, 11.0]` and `[2.0, 5.0, 51.0]`. The triangular reference checks every output against a direct all-pairs calculation with the same kernel. Resuming from the saved pair $(S_2,z_2)$ reproduces the final output. If you replace the sums at each step with one sum over the entire sequence, the first query can already see the third value.

## 7. Practical Takeaway

Measure two things on the same prompts. First, can a later query recover an earlier value when keys repeat or the answer changes halfway through the text? Second, how many bytes must the runtime retain per open request at each prefix length? A model can save memory on the longer prefixes and still miss a correction the task requires.

## Recent Work: Gating, Delta Updates, and Stateful Serving

**As of 2026-10-13.** Gated DeltaNet combines selective forgetting with targeted delta-rule updates and studies hybrid attention stacks [[4]](#ref-4). Its update can erase information already in memory before a new write, which affects subsequent reads.

An efficient layer still needs an exact state contract. Prefix reuse must restore recurrent state and any attention KV at the same position. Branching speculation must isolate state that cannot be rolled back by merely shortening a token buffer. The recent integration evidence in [Chapter 12.1](/chapter-12/kv-cache-management) and [Chapter 12.4](/chapter-12/speculative-decoding) explains why architecture-level memory gains require scheduler and recovery validation. Evaluate associative recall, position sensitivity, long-context quality, and cold-versus-restored continuation alongside throughput.


### October Deployment Case: Different Layers, Different State

**As of 2026-11-25**, Ling 3.1 Flash's public card specifies 63 KDA layers and nine gated-MLA layers, a 7:1 hybrid pattern [[5]](#ref-5). That is a concrete disclosed stack, not evidence that every “linear” model uses the same recurrence. Keep recurrent state and attention KV accounting separate; test exact recall, prefix reuse, branching and rollback against the actual runtime. Its hosted 1019 profile is not established as identical to the public weight revision. See Section 17.6 for the source-bound comparison.

## Muir: finite-state capacity depends on read and write dynamics

**As of 2026-11-25 — emerging research.** Muir studies channel-wise gated delta memory. It allocates low-rank gate capacity by sensitivity, adjusts readout across memory timescales, and introduces a boundary-pivoted chunkwise kernel. Its static and dynamic readout variants trade single-lag retention against multi-lag adaptability. Results on TPU-oriented kernels and tested recall tasks do not establish hardware-independent superiority. [[6]](#ref-6)

A useful evaluation separates isolated-needle retrieval, multiple dependent facts and continuous-text modeling. Compare quality at fixed parameter/compute budgets, numerical conditioning, and actual device throughput; sequence-linear complexity alone does not settle those questions.
