# 11.2 Audio and Speech Integration

Speech carries words, timing, speaker characteristics, prosody, and background sound. A transcript is a useful representation, but a text-only interface usually discards information not explicitly represented in it. A cascade can retain timestamps, speaker labels, or separate acoustic features; transcription does not force every system to discard all paralinguistic information.

The engineering choice is where to compress the signal and where to preserve temporal structure. A native audio interface can reduce some handoff costs, while introducing streaming, alignment, and interruption problems of its own.

## 1. Waveforms, Frames, and Token Rate

A mono waveform sampled at 16 kHz contains 16,000 samples per second; its stored dtype is a separate choice. An encoder converts it into lower-rate frames. A neural codec can then map each frame to discrete indices. Sound frame rate and serialized token rate are different quantities.

With $F$ frames per second and $Q$ codebooks, naive serial prediction uses $FQ$ token decisions per second. If each index has $N$ possibilities, the ideal fixed-rate index payload is $FQ\log_2N$ bits/s, excluding framing and entropy coding. At $F=50$, $Q=8$, and $N=1024$, this is 400 indices/s and 4,000 bits/s. A delayed or parallel multi-codebook schedule changes serial steps without changing this nominal payload.

## 2. Residual Vector Quantization

For encoded frame $x\in\mathbb R^d$, initialize residual $r_1=x$. At stage $q$, codebook $C_q$ has $N$ vectors of dimension $d$:

$$
i_q=\arg\min_{i\in\{1,\ldots,N\}}\|r_q-C_q[i]\|_2^2,\qquad
r_{q+1}=r_q-C_q[i_q],\qquad
\hat x=\sum_{q=1}^{Q}C_q[i_q].
$$

Here $i_q$ is the selected index and $\hat x$ the reconstructed feature frame. Later stages model residual error; they are not guaranteed to represent a particular semantic category. Decreasing residual norm also depends on the available codebook vectors and training, not simply on adding arbitrary random codebooks.

> **Educational forward-pass example:** This is an untrained nearest-codebook lookup, not a trained speech codec or a smoke-tested training pipeline. It omits the waveform encoder/decoder, commitment loss, straight-through or EMA learning, dead-code management, variable-length masks, distributed synchronization, and mixed-precision stability. Its random-feature output demonstrates tensor shapes only; it does not demonstrate intelligible audio or reconstruction quality.

```python
import torch
import torch.nn as nn

class ResidualVectorQuantizer(nn.Module):
    def __init__(self, num_quantizers=8, codebook_size=1024, dim=128):
        """
        Args:
            num_quantizers: Number of cascaded codebooks (Q)
            codebook_size: Number of vectors per codebook (N)
            dim: Dimension of each vector (d)
        """
        super().__init__()
        self.num_quantizers = num_quantizers
        self.codebooks = nn.ParameterList([
            nn.Parameter(torch.randn(codebook_size, dim))
            for _ in range(num_quantizers)
        ])

    def forward(self, x):
        # x shape: [batch_size, seq_len, dim]
        residual = x
        quantized_out = torch.zeros_like(x)
        token_indices = []

        for i in range(self.num_quantizers):
            codebook = self.codebooks[i]

            # Compute squared L2 distance: x^2 + y^2 - 2xy
            # residual^2: [batch, seq, 1]
            # codebook^2: [codebook_size]
            # matmul: [batch, seq, codebook_size]
            dist = (
                residual.pow(2).sum(dim=-1, keepdim=True)
                + codebook.pow(2).sum(dim=-1)
                - 2 * torch.matmul(residual, codebook.t())
            )

            # Find index of the closest codebook vector
            indices = torch.argmin(dist, dim=-1) # [batch_size, seq_len]
            token_indices.append(indices)

            # Lookup quantized vectors and accumulate
            quantized = codebook[indices]
            quantized_out += quantized

            # Update residual for the next quantizer stage
            residual = residual - quantized

        # token_indices shape: [batch_size, num_quantizers, seq_len]
        return quantized_out, torch.stack(token_indices, dim=1)

# Example execution simulating a 50Hz audio frame rate
batch_size = 2
seq_len = 50 # 1 second of audio
dim = 128

dummy_audio_features = torch.randn(batch_size, seq_len, dim)
rvq = ResidualVectorQuantizer(num_quantizers=8, codebook_size=1024, dim=128)
reconstructed, indices = rvq(dummy_audio_features)

print(f"Original features: {dummy_audio_features.shape}")
print(f"Reconstructed features: {reconstructed.shape}")
print(f"Token indices shape: {indices.shape}")
# Output: -> 8 tokens per frame
```

## 3. Discrete and Continuous Audio Modeling

AudioLM separates semantic and acoustic representations in a hierarchy [[1]](#ref-1). VALL-E studies codec language modeling conditioned on text and a speaker prompt [[2]](#ref-2). AudioPaLM combines text and speech representations to support speech tasks [[3]](#ref-3). These mechanisms differ; an audio-capable product name alone does not disclose which one a provider uses.

CALM studies autoregressive continuous audio latents with a consistency-based next-frame generator [[4]](#ref-4). Removing discrete quantization does not make the VAE lossless or eliminate every source of error. Compare fidelity, intelligibility, temporal stability, latency, and compute at matched task and hardware conditions rather than declaring continuous models universally preferable.

Text tokenization is deterministic for a fixed tokenizer and full input, but a word can tokenize differently with whitespace or surrounding text. Acoustic token variation likewise depends on the waveform and encoder context. Neither observation alone proves that one representation is context-free or that discrete prediction must fail.

## 4. October API Case: Voice Identity and Action Timing Are Separate Contracts

**As of 2026-10-18**, OpenAI's October 16 API update adds prompt-generated voices and nine natural voices for GPT-Live. The October 15 update adds native Decisions integration, enabling decisions while input or output transcript deltas arrive [[5]](#ref-5) [[6]](#ref-6). These are documented API capabilities; they do not reveal the model's codec, parameter count, or training mixture.

The engineering implication is to version the voice identity, audio session, and action policy separately. A transcript prefix can be revised, interrupted, or canceled. For “transfer fifty—actually fifteen,” an early decision must not become an irreversible transfer before the amount and authorization are settled. Use provisional decisions, cancellation identifiers, duplicate suppression, and independent execution checks. A changed voice must not change the action's permission boundary.

## 5. Streaming Evaluation and Practical Takeaway

Measure time to first audible output, inter-chunk gaps, end-to-end response latency, interruption detection and stop time, transcript revision stability, tool-action correctness, and cost per completed conversation. Evaluate noisy speech, accents, code-switching, overlapping speakers, silence, and disconnect/reconnect. Use intelligibility and human listening checks alongside word error rate; a correct transcript can still produce a poor spoken interaction.

Retain an immutable bundle of model/endpoint revision, codec or audio preprocessing where exposed, sample rate/channel conventions, voice ID, template, generation settings, tool schema, and safety/action policy. Keep test audio and speakers isolated from adaptation data. Canary a new voice or streaming configuration against the same conversations, gate on critical action errors and supported-language slices, and rehearse rollback of both session state and pending actions.

Audio integration is a joint representation and state-management problem. The following section generalizes those issues to multiple modalities without assuming a single shared encoder or unrestricted output generation.

**As of 2026-10-25**, the October 22 changelog marks Decisions with GPT-6 Luna generally available, including up to 400 questions per request, prompt caching and JSON input [[5]](#ref-5). Native voice integration is a capability contract, not a guarantee that acting on a partial transcript is safe. Evaluate transcript revisions, duplicate triggers, decision latency and authorization; see [Section 16.7](/chapter-16/decision-models-and-selective-prediction).

### Voxtral 3: Keep Speech Models and Agent Orchestration Separate

**As of 2026-10-25**, Mistral's October 20 changelog lists four Voxtral 3 models in **public API preview**: Mini TTS, Mini Transcribe, Mini Transcribe Realtime, and Small Transcribe. It also introduces a Voice Agents SDK/pipeline [[7]](#ref-7). The release offers self-deployment, which does not by itself establish a publicly downloadable open-weight checkpoint [[8]](#ref-8).

Treat these as different contracts: offline transcription, streaming transcription, speech synthesis, and an orchestrated agent are not interchangeable benchmarks. The TTS card and launch page describe different language coverage, so verify the exact SKU and endpoint before promising support [[8]](#ref-8) [[9]](#ref-9). Evaluate WER/CER and diarization for transcription, pronunciation and first-audio latency for TTS, and turn-taking, interruptions, transcript corrections, tool authorization and cost per completed task for the complete voice agent. Provider launch charts are not a matched end-to-end comparison of those systems.

## Quizzes

<details>
<summary>Quiz 1: Why are 50 frames/s and 400 codec indices/s compatible?</summary>
*Eight codebooks can produce eight indices per frame. Serial decision count depends additionally on the prediction schedule.*
</details>

<details>
<summary>Quiz 2: Does the RVQ forward example demonstrate a trainable speech codec?</summary>
*No. It demonstrates lookup shapes on random features. A codec needs trained encoders/decoders and appropriate learning, masking, and synchronization semantics.*
</details>

<details>
<summary>Quiz 3: Does replacing discrete tokens with continuous latents make audio generation lossless?</summary>
*No. Latent compression and generation still introduce error. Validate the full waveform output, not only the absence of quantization.*
</details>

<details>
<summary>Quiz 4: Why must a streaming decision be separated from a final tool effect?</summary>
*Partial speech may be revised or canceled before the request and permission are settled. An executor must enforce final arguments, authorization, and duplicate suppression.*
</details>

<details>
<summary>Quiz 5: Does compressing audio tokens directly compress the transformer's KV tensors by the same factor?</summary>
*No. Codec bitrate determines the input representation; KV storage depends on retained positions, KV heads, dimensions, layers, dtype, and cache policy. They are distinct budgets.*
</details>
