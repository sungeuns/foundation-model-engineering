# 20.2 Mamba와 S6

상태 공간 모델(State Space Models, SSM)의 개념은 선형 시간(Linear-time) 시퀀스 모델링을 위한 이론적 기반을 제공했지만, 이를 트랜스포머와 경쟁할 수 있는 수준으로 끌어올리기 위해서는 알고리즘과 하드웨어의 공동 설계(Co-design)가 필요했습니다. Mamba 계열은 하나의 완성된 종착점이라기보다, 빠르게 진화해 온 아이디어들의 연속으로 읽는 편이 더 적절합니다.

이 섹션에서는 Mamba-1의 **Selective Scan / S6** 에서 시작해, Mamba-2의 **Structured State Space Duality (SSD)** 를 거쳐, 2026년 ICLR에 등장한 **Mamba-3 (MIMO)** 논의까지의 흐름을 살펴봅니다. 먼저 용어부터 정리하면, S6는 “Mamba-1과 별개의 모델”이라기보다 Mamba-1 논문에서 selective SSM 계층을 설명할 때 쓰는 이름입니다. 실무에서는 보통 Mamba block, selective scan, S6가 같은 계열의 구현 세부를 가리키는 말로 섞여 쓰입니다.

## 1. Mamba-1의 선택적 스캔

Mamba-1은 입력 의존적인 $B,C,\Delta$ 를 사용합니다. [[1]](#ref-1) 구현에서 저장하는 $A$ 의 계수 배열은 $D\times N$ 이지만, 이는 채널마다 $N\times N$ 대각 행렬의 **대각 원소만** 저장한 것입니다. $D$ 는 채널 수, $N$ 은 채널별 상태 크기입니다. $D\times N$ 직사각형 배열 자체를 대각 행렬이라고 부르면 형태가 혼동됩니다.

Affine 전이를 연관적으로 결합하면 학습·prefill을 병렬 스캔으로 계산할 수 있습니다. Decode에서는 한 단계 상태 갱신이 가능합니다. 스캔 코어와 주변 투영은 다른 연산 특성을 가지므로 Mamba 전체가 행렬 곱을 사용하지 않는다고 보면 안 됩니다.


## 2. 구조화된 상태 공간 이중성 (Mamba-2)

Mamba-2는 **Structured State Space Duality (SSD)** 를 이용해 구조에 제약을 둔 선택적 SSM과 구조화된 마스크 어텐션을 연결합니다. 한 헤드 안의 상태 좌표 전체에 같은 스칼라 전이를 적용합니다. 연속 시간 표기로는 $A=\alpha I$ 이며, $I$ 는 단위 행렬, $\alpha$ 는 스칼라 계수입니다. 모든 선택적 SSM이 일반적인 softmax 어텐션과 같다는 뜻은 아닙니다. [[2]](#ref-2)

이에 대응하는 이산 전이에서 입력 위치 $j$ 가 출력 위치 $i$ 에 미치는 영향을 전달하는 인과적 전이 마스크는 그 사이 전이 계수의 곱입니다.

$$ \mathbf{L}_{ij} = \begin{cases} \prod_{k=j+1}^i a_k, & j \le i, \\ 0, & j>i. \end{cases} $$

$a_k$ 는 이산화된 스칼라 전이 계수입니다. 연속 시간의 $A$ 와 구분하며, 대각 원소는 빈 곱의 값인 1입니다. 전체 입력-출력 가중치에는 입력 계수 $B_j$ 와 읽기 계수 $C_i$ 도 들어갑니다. 마스크 $\mathbf L$ 만으로 층 전체를 나타내지는 못합니다.

### 세 단계로 직접 계산하기

초기 상태 $h_0=0$, 입력·출력 계수 1인 스칼라 상태 하나를 생각해봅시다. 직접 연결하는 skip 항은 생략합니다.

$$ h_t=a_t h_{t-1}+x_t,\qquad y_t=h_t. $$

$x_t$ 는 단계 $t$ 의 입력, $h_t$ 는 갱신한 상태, $y_t$ 는 출력입니다. $x=(2,4,1)^T$, $a=(0.75,0.5,0.25)^T$ 로 정합니다. 첫 전이는 0인 초기 상태에 곱해집니다. 이후 전이 계수는 서로 다르므로 고정 감쇠 계수 하나를 토큰 거리만큼 거듭제곱하면 잘못된 행렬이 나옵니다.

$x_3$ 을 바꿔도 $h_1$ 이나 $h_2$ 는 달라지지 않습니다. 그 위치에 대응하는 행렬 원소가 0이기 때문입니다. 초기 상태가 0이 아니라면 그 상태가 전파되는 기여도 더해야 합니다. 입력·출력 계수를 1로 둔 것은 전이 계수의 곱만 살펴보기 위해서이며, 입력 의존적인 Mamba-2 전체 계산을 구현한 것은 아닙니다. [[2]](#ref-2)

### 같은 식을 효율적으로 실행하기
SSD가 순환(Recurrence) 구조를 어텐션 행렬로 재구성했기 때문에, 이제 연산을 **청크 단위 행렬 곱셈 (Chunkwise matrix multiplication)** 으로 실행할 수 있게 되었습니다. 시퀀스는 블록(예: 64 토큰 청크)으로 나뉩니다.
1. **Intra-chunk (청크 내부):** 청크 *내부* 의 토큰 상호 작용은 표준 MatMul (선형 어텐션)을 사용하여 계산됩니다.
2. **Inter-chunk (청크 간):** 청크 경계를 넘는 상태 의존성을 전파합니다. Scan이나 구조화된 행렬곱으로 병렬화할 수 있어 반드시 순차 실행할 필요는 없습니다.

Mamba-2 논문의 2–8배 수치는 측정한 **SSM 코어** 의 속도이며 전체 학습의 동일 배수나 Tensor Core 100% 사용률을 뜻하지 않습니다. [[2]](#ref-2) 시퀀스·배치·상태 크기, 장치, 정밀도와 커널 버전을 함께 보고해야 합니다.

## 3. 이중성 구현하기

Mamba-2가 어떻게 순환 루프를 행렬 곱셈으로 변환하는지 정확히 이해하기 위해, 아래의 교육용 PyTorch 구현을 살펴보겠습니다. 이 코드는 SSD 프레임워크에서 파생된 청크 단위의 블록 내부 어텐션(Intra-block attention) 메커니즘을 시연합니다.

> **불완전한 교육용 청크 내부 계산.** 아래 코드는 청크 사이의 상태 전달을 생략하므로 전체 Mamba-2나 시퀀스 전체의 순환식과 동등하지 않습니다. 각 청크에서 기억이 초기화됩니다. 병렬 스캔·캐시·가변 길이 패딩과 sample packing 처리·수치 안정화·분산 실행은 생략합니다. 각 청크 내부의 인과 마스크는 코드에 포함되어 있습니다. 작은 FP32 텐서에서 청크 내부 행렬 곱만 살펴보세요.

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimplifiedSSD(nn.Module):
    """
    Structured State Space Duality (Mamba-2)의 교육용 구현체입니다.
    청크 단위 행렬 곱셈(Chunkwise MatMul) 접근 방식을 시연합니다.
    """
    def __init__(self, d_model: int, d_state: int, chunk_size: int = 64):
        super().__init__()
        self.d_model = d_model
        self.d_state = d_state
        self.chunk_size = chunk_size

        # Mamba-2는 A를 스칼라 곱 단위 행렬 구조로 제한합니다.
        # 채널당 하나의 스칼라를 학습합니다.
        self.A_log = nn.Parameter(torch.randn(d_model))

        # Mamba-2에서는 X, B, C, dt가 병렬로 투영(Projection)됩니다.
        self.in_proj = nn.Linear(d_model, d_model * 2 + d_state * 2)
        self.out_proj = nn.Linear(d_model, d_model)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        B_batch, L, D = x.shape

        # 시퀀스 길이를 chunk_size의 배수가 되도록 패딩합니다.
        pad_len = (self.chunk_size - (L % self.chunk_size)) % self.chunk_size
        if pad_len > 0:
            x = F.pad(x, (0, 0, 0, pad_len))

        L_padded = x.shape[1]
        num_chunks = L_padded // self.chunk_size

        # 1. 병렬 투영 (Parallel Projection)
        proj = self.in_proj(x)
        x_proj, dt_raw, B_mat, C_mat = torch.split(
            proj,
            [self.d_model, self.d_model, self.d_state, self.d_state],
            dim=-1
        )
        dt = F.softplus(dt_raw)

        # 2. A 이산화 (Scalar-times-identity)
        A = -torch.exp(self.A_log) # (D,)
        dA = torch.exp(dt * A)     # (B, L, D)

        # 청크 단위로 형태 변환: (Batch, Chunks, ChunkSize, Dim)
        x_chunks = x_proj.view(B_batch, num_chunks, self.chunk_size, D)
        B_chunks = B_mat.view(B_batch, num_chunks, self.chunk_size, self.d_state)
        C_chunks = C_mat.view(B_batch, num_chunks, self.chunk_size, self.d_state)
        dA_chunks = dA.view(B_batch, num_chunks, self.chunk_size, D)

        # 3. 청크에 대한 반분리 거리 마스크(Semi-separable distance mask) 계산
        # L_{i,j} = \prod_{k=j+1}^i dA_k
        # 이 교육용 구현은 각 청크의 이차 크기 마스크를 직접 만듭니다.
        mask = torch.ones(B_batch, num_chunks, self.chunk_size, self.chunk_size, D, device=x.device)
        for i in range(self.chunk_size):
            for j in range(i):
                mask[:, :, i, j, :] = torch.prod(dA_chunks[:, :, j+1:i+1, :], dim=2)

        # 인과적 마스킹 적용 (하삼각 행렬)
        causal_mask = torch.tril(torch.ones(self.chunk_size, self.chunk_size, device=x.device))
        mask = mask * causal_mask.view(1, 1, self.chunk_size, self.chunk_size, 1)

        # 4. B 이산화 및 상태 V 계산
        dB_chunks = dt.view(B_batch, num_chunks, self.chunk_size, D).unsqueeze(-1) * B_chunks.unsqueeze(-2)
        V = dB_chunks * x_chunks.unsqueeze(-1) # (B, Chunks, ChunkSize, D, d_state)

        # 5. 청크 내부 어텐션 (Intra-chunk Attention): Y = C * (Mask @ V)
        # 시퀀스 차원 'j'를 따라 V에 마스크를 곱합니다.
        attn_out = torch.einsum('bnijd,bnjde->bnide', mask, V)
        Y_intra = torch.einsum('bnide,bnie->bnid', attn_out, C_chunks) # (B, Chunks, ChunkSize, D)

        # [참고]: 청크 간 순환(Inter-chunk recurrence, 청크 간에 은닉 상태를 전달하는 과정)은
        # 간결성을 위해 여기서는 생략되었지만, 유사한 블록 단위 업데이트를 따릅니다.

        y = Y_intra.view(B_batch, L_padded, D)
        if pad_len > 0:
            y = y[:, :L, :]

        return self.out_proj(y)
```

## 4. Mamba-3 연구 사례

**2026-11-18 기준, 인용한 2026년 논문.** Mamba-3는 이산화에서 유도한 순환식, 복소 상태와 MIMO를 결합해 상태 추적과 decode 효율을 연구합니다. [[3]](#ref-3) MIMO 변형의 1.5B 실험에서 보고된 1.8 percentage-point 이득은 Mamba-2가 아니라 Gated DeltaNet 기준선과의 비교입니다. 별도의 상태 크기 실험에서는 Mamba-2의 절반 상태 크기로 비슷한 perplexity를 보고합니다.

두 결과는 다른 비교입니다. 복소 상태와 MIMO가 모든 작업에서 동일 지연으로 품질을 개선한다는 보장은 없습니다. 상태 정밀도·메모리·커널을 포함한 같은 자원 조건에서 검증해야 합니다.


## 5. 비교할 설계 축

| 설계 | 핵심 선택 | 검증할 비용과 한계 |
| :--- | :--- | :--- |
| Mamba-1 | 채널별 대각 전이와 선택적 스캔 | 상태 용량, 스캔과 투영의 비용 |
| Mamba-2 | 상태 축에 공통인 스칼라 전이와 SSD | 청크 내부·사이 계산, 코어와 전체 모델 속도 |
| Mamba-3 | 복소 상태·MIMO·이산화 변경 | 상태 추적, 정밀도, 실제 decode 지연 |


## 6. 워크로드에 따른 선택

- **계속 들어오는 긴 스트림:** 로그·센서·오디오 등에서는 고정 크기 상태가 유용할 수 있습니다. 상태가 보존해야 할 정보를 평가하세요.
- **정확한 검색:** 순수 SSM, 어텐션, 하이브리드 후보를 같은 회상 테스트로 비교합니다. 하이브리드라고 정답이 보장되지는 않습니다.
- **Decode 비용:** KV가 실제 병목이면 순환 모델을 검토하되 투영, 상태 갱신과 커널 지원까지 포함합니다.
- **범용 작업:** 모델 계열 이름보다 요구 작업의 품질·비용·지연 시간 기준으로 선택합니다.

선형 복잡도뿐 아니라 실제 장치의 산술 집약도, 커널 성숙도, 배치·길이 분포와 정확한 회상 성능을 함께 확인해야 합니다.



## 7. 실무적 정리

이 계열의 핵심은 순환식과 하드웨어 실행을 함께 설계한다는 점입니다. 고정 크기 상태가 무한한 기억을 보장하지는 않습니다. 정확한 회상과 장기 상태 추적, 양자화 후 안정성, 접두사 복원과 롤백을 작업별로 검증해야 합니다.
