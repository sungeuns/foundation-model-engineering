# 20.6 확산 기반 LLM

자기회귀 decoder는 왼쪽에서 오른쪽으로 토큰을 확정합니다. 확산형 언어 모델은 손상된 텍스트를 복원하도록 학습하고, 여러 step에서 여러 위치를 고칠 수 있습니다. 핵심 차이는 생성 schedule이지 Transformer의 제거가 아닙니다. denoiser도 Transformer backbone을 사용할 수 있습니다.

11.4절의 이미지 확산과 연결되지만 중요한 차이가 있습니다. 이미지는 연속 pixel·latent 공간에서 손상할 수 있고, 텍스트는 연속 완화나 이산 토큰 손상 과정이 필요합니다. 어느 쪽도 더 빠른 서빙이나 더 좋은 추론을 보장하지 않습니다.

## 1. 연속 방식과 이산 방식

**임베딩 확산** 은 연속 토큰 표현에 노이즈를 넣고 제거하도록 학습합니다. Diffusion-LM이 초기 사례입니다 [[1]](#ref-1). 결과 벡터를 토큰으로 바꾸는 과정은 학습된 어휘 decoder나 rounding을 사용할 수 있으며, 둘은 같은 연산이 아닙니다.

**이산 확산** 은 토큰 자체를 바꾸며 mask 토큰으로 치환하는 경우가 많습니다. denoiser는 일부만 보이는 시퀀스에서 빠진 토큰을 예측합니다 [[2]](#ref-2). 토큰 ID에 Gaussian noise를 더하는 것과는 다릅니다. 손상 schedule과 역방향 sampler가 수정 가능한 위치와 확정 시점을 정합니다.

어휘 크기가 $V$ 일 때 균일 범주형 전이는 다음과 같습니다.

$$
Q_t=(1-\beta_t)I+\beta_t\frac{\mathbf 1\mathbf 1^\top}{V},
$$

$\beta_t\in[0,1]$ 는 step-$t$ 손상 확률, $I$ 는 $V\times V$ 항등 행렬, $\mathbf1$ 은 모든 원소가 1인 벡터입니다. 이 특정 전이 계열에서는

$$
\bar Q_t=\bar\alpha_t I+(1-\bar\alpha_t)\frac{\mathbf1\mathbf1^\top}{V},\qquad
\bar\alpha_t=\prod_{s=1}^t(1-\beta_s).
$$

깨끗한 one-hot 행벡터 $x_0$ 의 손상 분포는 $x_0\bar Q_t$ 입니다. absorbing-mask 과정은 mask 상태를 포함하는 다른 전이 행렬을 사용합니다. 균일 토큰 식을 모든 mask형 diffusion 언어 모델에 적용하지 않습니다.

## 2. 공개 근거가 추가한 것

**2026-10-13 기준 연구·공개 스냅샷.** LLaDA는 mask형 diffusion 모델을 처음부터 학습하고 SFT를 적용해, 보고한 기준 모델과 비교하며 8B 규모의 언어 모델·지시 이행 역량을 보여 줍니다 [[3]](#ref-3). 작은 제어 가능 생성 prototype을 넘어서는 근거입니다. 모든 diffusion 목적이 같은 자원의 자기회귀 모델보다 낫다는 증거는 아닙니다.

Mercury 2.5의 공개는 diffusion형 decoding을 호스팅 상용 서비스 비교로 연결합니다 [[4]](#ref-4). 제공사의 지연·처리량 주장은 해당 작업량의 주장으로 다룹니다. 인용한 발표문은 아키텍처·데이터 혼합·샘플링 구현을 완전히 공개하지 않습니다. 제품 접근과 독립 재현 가능한 공개 가중치 학습법은 서로 다른 근거 범주입니다.

기회는 유연한 생성입니다. infilling, 이미 보이는 위치의 제약, block 단위·임의 순서 정제가 가능합니다. 위험은 반복되는 전체 block 연산, 이른 확정, 정제 후에도 남는 오류, streaming 도구·접두사 캐시와의 복잡한 결합입니다.

## 3. sampler도 모델 품질의 일부다

denoiser 학습만으로 완전한 decoder가 정해지지는 않습니다. sampler는 다음을 결정합니다.

- 출력·block 길이와 정제 step 수
- mask·공개·remask할 위치
- confidence 경계·temperature·토큰 선택 순서
- 프롬프트와 변경 불가능한 사용자 제약의 가시성
- EOS 처리와 block을 안전하게 streaming하는 시점

전체 시퀀스 sampler는 출력 길이 가정이 필요할 수 있습니다. block sampler는 응답을 점진적으로 확장하지만 이 경우 “답 전체를 병렬 생성한다”는 설명은 부정확합니다. confidence 기반 공개는 초기 오류를 확정할 수 있고, remasking은 개선하거나 불안정하게 만들 수 있습니다. schedule 변경을 시스템 변경으로 보고 같은 예산·출력 정책에서 평가합니다.

## 4. 보편적 속도 주장 없는 비용 모델

$L$ 은 생성 길이, $T$ 는 정제 step 수, $C_{block}(L)$ 은 해당 block의 denoising pass 비용입니다. 대략적인 diffusion 비용은 $T C_{block}(L)$ 에 conditioning·decoding·스케줄링을 더한 값입니다. 자기회귀 서빙은 점진적 step 비용을 합산하며 캐시한 접두사 상태를 재사용할 수 있습니다. $T$ 와 $L$ 만 비교하면 전체 block pass와 캐시한 한 토큰 step의 차이를 놓칩니다.

첫 **사용 가능한** 출력까지의 시간, 전체 완료 시간, p95 지연, accelerator-second당 토큰·과업, peak memory, 고정 총예산 품질을 측정합니다. 최종 출력뿐 아니라 remask·재계산한 위치도 셉니다. 동시성·긴 프롬프트·짧은 답·code infill·정확한 제약·도구 경계 지연을 포함합니다. block 완료가 빨라도 즉각적인 토큰 streaming이 필요한 서비스에는 맞지 않을 수 있습니다.

## 5. 학습·아티팩트 계약

이 절은 계약을 설명하며 실행 가능한 학습 코드를 제공하지 않습니다. 모의 forward pass나 무작위 임베딩의 어휘 logits 투영은 역방향 diffusion sampler 구현이 아닙니다.

입력 checkpoint 또는 처음부터의 초기화, mask/special token을 포함한 토크나이저, 고유 채팅 템플릿, 데이터 manifest, denoising 목적·noise 가중치, 손상 schedule, 출력/시퀀스 cap, optimizer·학습률·토큰 배치·seed·정밀도·sharding·재계산을 고정합니다. reference checkpoint ID 또는 명시적 미사용을 밝힙니다. RL 확장은 별도 보상·reference 계약이 필요합니다.

지시 학습에서는 손상 전에 assistant 구간을 식별합니다. 선언한 conditioning 목적에 따라 prompt·외부 도구 문맥은 손상하지 않습니다. 명시적 mask로 padding·사용자/도구 target·종료 이후를 학습 손실에서 제외합니다. BOS/EOS·`add_generation_prompt`·잘림·학습/서빙 템플릿 일치를 확인합니다. noise 가중치, mask된 토큰이 없는 경우, 가변 길이 집계, packing한 episode 사이의 어텐션 경계도 명시해야 합니다.

파라미터·gradient·optimizer·activation·임시 버퍼·collective·checkpoint·평가 자원을 분리합니다. 반복 정제는 자기회귀 서빙과 다른 캐시·workspace 가정이 필요할 수 있습니다. 출처·라이선스/동의·PII 처리·필터/혼합 버전·토크나이저 리비전·sample ID·shard hash를 보존합니다. 분할 전에 중복 제거·군집화를 수행하고 공개/비공개 평가와 합성 파생 예시를 격리합니다.

토큰 정규화 학습/검증 손실과 도메인 구간, mask 비율, noise별 손실, remasking·EOS/잘림, nonfinite/overflow, gradient/activation norm, 처리량, MFU, 데이터 대기, collective/straggler, 재구성 가능한 batch ID를 관측합니다. 책임자·관측 구간을 사전 정의하고 수치 불안정·padding 유출·길이 폭주·고정 예산 holdout 퇴행이 있으면 중단합니다.

sharded 모델/optimizer, scheduler, scaler/FP8 상태, 전역 step/토큰 수, RNG, sampler 상태, 정확한 데이터 커서, 데이터/토크나이저/config hash를 checkpoint합니다. checksum·완료 표식으로 원자적 게시를 수행하고 보존·복제·world-size 제한·학습 연속성 동등성 복원 훈련을 정의합니다. 모델/템플릿/sampler/도구/안전 묶음은 도메인·기존 역량 유지·안전·형식/도구·지연·비용·오류율 조건을 짝지은 불확실성이나 근거 있는 표본 수로 통과한 뒤 출시합니다. 정상 동작이 확인된 이전 sampler와 checkpoint로 전환하는 훈련을 합니다.

## 6. 실무적 결론

확산 언어 모델은 답을 만들고 수정하는 다른 schedule을 제공합니다. 가치는 목적함수·sampler·커널·과업 제약·서빙 조건에 달려 있습니다. denoising step이 적다는 이유로 효율성을 추론하지 말고 전체 시스템으로 평가합니다. 다음 절은 이런 발전이 행동 조건부 world modeling을 어떻게 지원하는지 살펴봅니다.
