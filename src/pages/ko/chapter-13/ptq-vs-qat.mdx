# 13.1 PTQ vs QAT

이전 장에서 우리는 긴 컨텍스트(Long Context) 추론 시 발생하는 동적 메모리(KV Cache) 오버헤드를 Chunked Prefill과 분리형 서빙(Disaggregated Serving) 같은 시스템 엔지니어링으로 해결하는 방법을 살펴보았습니다. 하지만 컨텍스트 윈도우를 최적화하더라도, 모델의 정적 가중치(Static Weights) 자체가 차지하는 거대한 메모리 장벽은 그대로 남아있습니다. 16비트 정밀도(BF16)를 사용하는 70B(700억 개) 파라미터 모델은 가중치를 메모리에 올리는 데만 140GB 이상의 VRAM을 요구하며, 이는 소비자용 하드웨어에서의 구동을 원천적으로 차단하고 기업의 서빙 인프라 비용을 기하급수적으로 증가시킵니다.

이 물리적 한계를 돌파하기 위한 핵심 기술이 바로 **양자화** (Quantization)입니다. 양자화는 고정밀 부동소수점(FP32/BF16) 값을 더 낮은 정밀도의 이산적인 정수 구간(INT8, INT4 등)으로 매핑하는 수학적 압축 과정입니다.

양자화 연구 분야는 모델이 이러한 압축 과정에서 발생하는 '노이즈(오차)'를 언제, 그리고 어떻게 대면하는지에 따라 두 가지 패러다임으로 나뉩니다. 바로 **학습 후 양자화** (Post-Training Quantization, PTQ)와 **양자화 인지 학습** (Quantization-Aware Training, QAT)입니다.

---

## 1. 선형 양자화의 수학적 이해 (Linear Quantization)

두 패러다임을 나누기에 앞서, 기저에 깔린 공통적인 수학적 원리를 이해해야 합니다. 가장 널리 사용되는 압축 방식은 **선형 양자화** (Affine Quantization)입니다. 이 방식은 스케일 팩터(Scale Factor) $S$ 와 제로 포인트(Zero-point) $Z$ 를 사용하여 고정밀 텐서 $x$ 를 양자화된 정수 텐서 $q$ 로 매핑합니다.

$$
q = \text{clip}\left(\lfloor \frac{x}{S} + Z \rceil, q_{\text{min}}, q_{\text{max}}\right)
$$

추론 시 하드웨어는 행렬 곱셈에 이 정수 연산을 사용하며, 그 결과는 다시 부동소수점 표현으로 역양자화(Dequantization)됩니다.

$$
x_{\text{approx}} = S \times (q - Z)
$$

이때 원본 $x$ 와 복원된 $x_{\text{approx}}$ 사이의 차이가 바로 **양자화 오차** (Quantization Error)입니다. PTQ와 QAT의 근본적인 차이는 이 오차를 시스템이 어떻게 다루느냐에 있습니다.

## 2. Post-Training Quantization (PTQ)

PTQ는 사전 학습된 체크포인트를 낮은 정밀도 표현으로 변환합니다. 단순 반올림부터 데이터 기반 오차 보정과 재구성까지 여러 방법이 있으며, 모든 방법이 가중치를 그대로 동결하거나 활성값 캘리브레이션을 요구하는 것은 아닙니다. 가중치만 양자화하거나 데이터 없이 변환하는 방법도 있습니다.

### 캘리브레이션의 범위

정적 활성값 양자화에서는 대표 입력으로 범위를 추정합니다. 표본 수, 도메인·길이·언어 분포, 클리핑 목표를 기록해야 합니다. 분포 변화는 포화와 오차를 늘릴 수 있지만 반드시 치명적인 붕괴를 일으키는 것은 아닙니다. 활성값 분포, 포화율, 미노출 평가와 실제 커널의 출력을 함께 검사합니다.

### PyTorch를 이용한 캘리브레이션 루프 엔지니어링

아래는 선형 레이어(Linear Layer)에 대해 대칭적(Symmetric) Min-Max 캘리브레이션을 수행하는 PyTorch 구현 예시입니다.

> **의도적으로 단순화한 예제.** 하나의 양자화 연산을 분리하며 실제 packed kernel·보정/export 일치·토크나이저/loss mask·분산 상태·전체 학습 루프는 생략합니다. smoke test한 운영 구현이 아닙니다.

```python
import torch
import torch.nn as nn

class PTQLinear(nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        self.weight = nn.Parameter(torch.randn(out_features, in_features))
        self.bias = nn.Parameter(torch.zeros(out_features))
        self.weight_scale = None
        self.act_scale = None

    def calibrate(self, x):
        """
        절대 최댓값을 기반으로 스케일을 캘리브레이션합니다.
        실제 프로덕션에서는 이동 평균(Moving Average)이나 KL 발산(KL-divergence)을
        사용하여 이상치(Outlier)에 대한 견고성을 높입니다.
        """
        # 활성화 값 캘리브레이션 (INT8 범위: -128 ~ 127)
        max_act = torch.max(torch.abs(x))
        self.act_scale = (max_act / 127.0).detach().clamp_min(torch.finfo(x.dtype).tiny)

        # 가중치 캘리브레이션
        max_w = torch.max(torch.abs(self.weight))
        self.weight_scale = (max_w / 127.0).detach().clamp_min(torch.finfo(self.weight.dtype).tiny)

    def forward(self, x):
        if self.weight_scale is None:
            # 캘리브레이션 이전의 일반적인 순전파
            return nn.functional.linear(x, self.weight, self.bias)

        # 양자화된 추론 시뮬레이션 (실제 하드웨어에서는 INT8/INT32로 실행됨)
        q_w = torch.clamp(torch.round(self.weight / self.weight_scale), -128, 127)
        q_x = torch.clamp(torch.round(x / self.act_scale), -128, 127)

        # INT32 누산 (Accumulation)
        out = nn.functional.linear(q_x, q_w)

        # 다음 레이어를 위해 부동소수점으로 역양자화 (Dequantize)
        return out * (self.weight_scale * self.act_scale) + self.bias

# 실행 예시
layer = PTQLinear(128, 64)
calibration_data = torch.randn(32, 128) # 실제 환경의 데이터를 완벽히 대변해야 함!

layer.calibrate(calibration_data)
output = layer(calibration_data)
print(f"Quantized Output Shape: {output.shape}")
```

## 3. Quantization-Aware Training (QAT): 능동적 접근

PTQ에 보편적인 8비트 또는 4비트 품질 하한은 없습니다. 낮은 정밀도는 오차를 키울 수 있지만 실제 결과는 모델·보정 분포·그룹 크기·방법에 달려 있습니다. QAT는 추가 학습으로 적응할 수 있으나 비용과 과적합·기본 능력 회귀 가능성도 평가해야 합니다.

**QAT** 는 최적화 과정을 바꿉니다. 사후에 양자화하는 대신, QAT는 학습 또는 파인튜닝 과정 중에 연산 그래프(Computational Graph) 내부에 '가짜 양자화(Fake Quantization)' 노드를 삽입합니다. 모델의 옵티마이저(Optimizer)는 순전파 시에 양자화 오차를 직접 '목격'하고, 역전파(Backward-pass) 시에 이를 보상하기 위해 마스터 가중치를 조정합니다. 즉, 모델이 저정밀도 환경에서 살아남는 법을 스스로 학습하는 능동적인 방식입니다.

> **가상의 손실 지형 대신 내보낸 모델을 비교하세요.** QAT는 가중치가 양자화에 적응할 기회를 제공하지만 더 좋은 최솟값을 보장하지는 않습니다. 같은 미노출 평가 과제, 목표 정밀도, 배포 커널에서 PTQ와 QAT를 비교하고 추가 적응 비용도 포함하세요.

### Straight-Through Estimator (STE)의 수학적 속임수

QAT를 구현할 때 직면하는 가장 큰 수학적 장애물은 `round()` (반올림) 함수입니다.
`round()` 와 같은 계단 함수의 미분값은 거의 모든 곳에서 0이며, 계단 부분에서는 정의되지 않습니다. 표준 역전파를 그대로 실행하면, 양자화 노드에서 기울기(Gradient)가 0이 되어 가중치 업데이트가 완전히 멈추게 됩니다.

이를 해결하기 위해 QAT는 **Straight-Through Estimator (STE)** [[1]](#ref-1) 를 사용합니다. 역전파 과정에서 STE는 `round()` 연산을 단순히 무시하고, 해당 노드의 로컬 기울기를 $1$ 로 간주하여 기울기를 통과시킵니다.

$$
\frac{\partial L}{\partial x} = \frac{\partial L}{\partial q} \cdot \frac{\partial q}{\partial x} \approx \frac{\partial L}{\partial q} \cdot 1
$$

### STE를 활용한 Fake Quantization 엔지니어링

> **의도적으로 단순화한 예제.** 하나의 양자화 연산을 분리하며 실제 packed kernel·보정/export 일치·토크나이저/loss mask·분산 상태·전체 학습 루프는 생략합니다. smoke test한 운영 구현이 아닙니다.

```python
import torch
import torch.nn as nn

class RoundSTE(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x):
        return torch.round(x)

    @staticmethod
    def backward(ctx, grad_output):
        # Straight-Through Estimator: 기울기를 변경 없이 그대로 통과시킴
        return grad_output

def fake_quantize(tensor, scale, bits=4):
    q_max = (1 << (bits - 1)) - 1
    q_min = -(1 << (bits - 1))

    # STE를 사용한 스케일링 및 반올림
    scaled = tensor / scale
    rounded = RoundSTE.apply(scaled)

    # 클리핑 및 역양자화
    clipped = torch.clamp(rounded, q_min, q_max)
    return clipped * scale

class QATLinear(nn.Module):
    def __init__(self, in_features, out_features, bits=4):
        super().__init__()
        # 마스터 가중치는 전체 정밀도(FP32/BF16)로 유지됨
        self.weight = nn.Parameter(torch.randn(out_features, in_features) * 0.02)
        self.bias = nn.Parameter(torch.zeros(out_features))
        if bits < 2:
            raise ValueError("this signed integer example requires bits >= 2")
        self.bits = bits

    def forward(self, x):
        # 가중치에 대한 스케일을 동적으로 계산
        w_max = self.weight.detach().abs().max()
        q_max = (1 << (self.bits - 1)) - 1
        w_scale = (w_max / q_max).clamp_min(torch.finfo(self.weight.dtype).tiny)

        # 가짜 양자화(Fake Quantization) 적용
        q_weight = fake_quantize(self.weight, w_scale, self.bits)

        # 순전파는 양자화된 가중치를 사용하지만, 연산 그래프는
        # STE를 통해 전체 정밀도인 self.weight로 기울기를 라우팅함.
        return nn.functional.linear(x, q_weight, self.bias)

# 실행 예시
layer = QATLinear(128, 64, bits=4)
x = torch.randn(32, 128)
out = layer(x)
loss = out.sum()
loss.backward()

# 기울기가 전체 정밀도 가중치로 성공적으로 흘러 들어옴!
print(f"Master Weight Gradient Shape: {layer.weight.grad.shape}")
```

## 4. 메모리와 혼합 정밀도 설계

QAT 메모리는 학습 대상·master weight 정밀도·optimizer 상태·activation·fake quantization 중간값의 materialization/fusion에 달려 있습니다. 일반 학습의 두 배이거나 LoRA와 같다고 일반화할 수 없습니다. 파라미터·gradient·optimizer·activation·임시 버퍼·collective·checkpoint·평가를 분리하고 정밀도·sharding·재계산·시퀀스 길이를 명시합니다.

혼합 정밀도는 측정한 민감도와 커널 지원에 따라 tensor·레이어에 format을 배분합니다. 학습된 quantization scale은 격자를 조절하지만 bit-width 자체를 선택하지는 않습니다. 초기·최종 레이어는 민감도 sweep 후보이지 반드시 예외가 되는 것은 아닙니다. 정확한 packed format·hardware에서 품질과 실제 속도를 비교하며 cache 정밀도와 가중치 정밀도도 구분합니다.

base/토크나이저/템플릿·보정/학습 데이터 manifest·목적·양자화 granularity·optimizer/학습률·학습 모듈·응답 cap·reference ID 또는 미사용·export kernel을 고정합니다. native-template SFT에는 assistant mask·BOS/EOS·잘림/padding·가변 길이 집계·packing 격리가 필요합니다. 평가를 격리하고 출처·라이선스·필터 버전·sample ID·shard hash를 남깁니다.

토큰 정규화 손실·도메인/역량 유지 구간·nonfinite/overflow·gradient/activation norm·saturation/양자화 오차·처리량·MFU·데이터 대기·collective/straggler를 batch ID와 관측합니다. 사전 수치·품질 경계에서 중단합니다. 전체 sharded 학습 상태·scheduler/scaler·RNG·sampler/데이터 커서·아티팩트 hash를 저장하고 가중치·scale·packing 메타데이터·커널 조건을 checksum으로 원자적 export합니다. 복원·rollback을 훈련하고 export한 아티팩트의 짝지은 품질·안전·형식/도구·지연·비용·오류를 검사합니다. fake quantization 학습 품질만으로 배포 packed kernel을 검증할 수는 없습니다.

## 5. 인터랙티브 시각화: 양자화 오차 시뮬레이터

인터랙티브는 직접 정한 스칼라 8개의 반올림·클리핑 오차를 계산합니다. PTQ·QAT의 순전파 양자화는 같고 QAT 모드는 clipped straight-through 기울기를 설명합니다. 학습한 분포나 모델 품질 벤치마크가 아닙니다.

## 6. 요약 및 비교

| 특징 | Post-Training Quantization (PTQ) | Quantization-Aware Training (QAT) |
| :--- | :--- | :--- |
| **복잡도** | 보정·변환, 작업 부하에 따라 다름 | 추가 학습·적응 |
| **필요 데이터** | 알고리즘에 따라 대표성 있는 보정셋 또는 data-free 방식 | 목적에 맞는 대표성 있는 적응 데이터 |
| **정확도 유지력** | format·보정·모델·과업에 따라 다름 | 일부 저비트 품질을 회복할 수 있으나 보장은 아님 |
| **메모리 오버헤드** | 거의 없음 | 학습 상태·커널 구현에 따라 다름 |
| **최적 사용 사례** | 제한된 적응 예산의 압축 | PTQ가 품질 기준을 통과하지 못할 때 적응 |

다음 섹션에서는 이러한 이론적 패러다임에서 파생된 구체적인 알고리즘들(GPTQ, AWQ, GGUF)을 살펴보고, 최신 하드웨어 아키텍처 위에서 양자화된 텐서들이 물리적으로 어떻게 배치되고 연산되는지 깊이 파헤쳐 보겠습니다.

*`round()` 와 같은 계단 함수의 수학적 미분값은 거의 모든 구간에서 0이며, 반정수 지점(n + 0.5)에서는 정의조차 되지 않습니다. 만약 표준 역전파 알고리즘을 그대로 적용한다면, 연산 그래프를 타고 내려오던 기울기(Gradient)가 양자화 노드에서 0과 곱해져 소멸되어 버립니다. STE는 이 노드에서의 로컬 기울기를 강제로 1로 근사하여 통과시킴으로써, 손실(Loss)에 대한 기울기가 전체 정밀도(FP32) 마스터 가중치까지 무사히 도달해 업데이트될 수 있도록 만듭니다.*
</details>

<details>
<summary>Quiz 3: 혼합 정밀도를 선택할 때 어떤 검증이 필요한가요?</summary>
*층별 민감도, 실제 포맷의 메타데이터·커널 지원, 정확도와 지연 시간을 측정해야 합니다. 첫 층과 마지막 층이 항상 가장 민감한 것은 아니며 균일한 정밀도가 구현과 실행 효율에서 유리할 수도 있습니다.*
</details>

<details>
<summary>Quiz 4: QAT는 PTQ와 무엇이 다르며 왜 항상 더 좋지는 않나요?</summary>
*QAT는 학습 중 양자화 오차를 모사해 가중치를 적응시키지만, PTQ는 이미 학습된 가중치를 변환합니다. 이점은 데이터·예산·정밀도·커널에 달려 있으며 실제 export 아티팩트의 품질과 비용을 평가해야 합니다.*
</details>

<details>
<summary>Quiz 5: 이 예제의 STE는 클리핑 범위 밖에서도 기울기를 그대로 통과시키나요?</summary>
*아닙니다. RoundSTE의 역전파는 항등 함수지만, 뒤따르는 clamp는 반올림된 값이 범위를 벗어나면 기울기를 0으로 만듭니다. scale을 detach했으므로 별도의 scale 경로로 기울기가 흐르지 않습니다. 원래 입력에 범위 마스크를 적용하는 구현과도 경계에서 다를 수 있습니다.*
</details>
