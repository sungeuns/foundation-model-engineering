# 11.5 비디오 생성의 기초

비디오 생성은 외형과 시간에 따른 변화를 함께 표현해야 합니다. 압축된 시공간 격자를 떠올리면 이해하기 쉽습니다. 오토인코더는 어떤 세부 정보가 압축 후에도 남는지 결정하고, 잡음 제거 모델은 위치 사이의 의존성을 학습합니다. 격자나 전체 어텐션 마스크 자체가 물리 엔진을 제공하지는 않습니다.

2024년 Sora 보고서는 압축된 시공간 패치와 정성적 강점뿐 아니라 **실패 사례** 도 설명하지만 전체 학습법은 공개하지 않습니다. [[1]](#ref-1) FullDiT는 전체 어텐션을 통한 공동 조건 처리를 연구합니다. [[2]](#ref-2) Wan은 별도의 기술 보고서가 있는 비디오 모델 계열입니다. [[3]](#ref-3) 여기서는 구조를 이해하기 위한 사례로 다루며 최신 순위를 뜻하지 않습니다. 날짜가 명시된 상용 모델 현황은 다음 절에서 다룹니다.

## 1. 비디오 잠재 표현을 패치로 바꾸기

잠재 텐서의 형태를 $(B,C,T,H,W)$ 라고 하겠습니다. 각각 배치, 채널, 시간 위치, 높이, 너비입니다. 겹치지 않는 패치의 크기가 $(p_t,p_h,p_w)$ 이고 각 차원이 정확히 나누어지면 토큰 수는 다음과 같습니다.

$$ n=\frac{T}{p_t}\frac{H}{p_h}\frac{W}{p_w} $$

여기서 $T$ 는 **잠재 표현의** 시간 위치 수입니다. 원본 프레임 수를 알려면 오토인코더의 시간 압축률도 알아야 합니다. 패치 투영은 각 블록을 폭 $d$ 의 벡터로 바꿉니다.

> **교육용 텐서 연산.** 아래 코드는 합성 잠재 텐서의 형태를 검사하고 투영할 뿐입니다. 학습된 오토인코더, 위치 인코딩, 잡음 제거 모델, 조건 처리, 샘플러가 없으므로 비디오를 생성할 수 없습니다.

```python
import torch
import torch.nn as nn

class SpacetimePatchEmbed(nn.Module):
    """
    Converts a 3D latent video volume into a 1D sequence of spacetime tokens.
    """
    def __init__(self, in_channels=4, embed_dim=1152, patch_size=(2, 2, 2)):
        super().__init__()
        self.patch_size = patch_size

        # A 3D Convolution acts as the patch extraction and linear projection simultaneously.
        # The stride equals the patch size to ensure non-overlapping 3D patches.
        self.proj = nn.Conv3d(
            in_channels, embed_dim,
            kernel_size=patch_size,
            stride=patch_size
        )

    def forward(self, x):
        # x shape: (Batch, Channels, Time, Height, Width)
        B, C, T, H, W = x.shape
        if any(size % patch for size, patch in zip((T, H, W), self.patch_size)):
            raise ValueError("latent dimensions must be divisible by patch dimensions")

        # Extract and project patches
        x = self.proj(x)
        # Output shape: (Batch, embed_dim, T', H', W')
        # where T' = T // patch_size, H' = H // patch_size, etc.

        # Flatten the spatial and temporal dimensions into a single sequence dimension
        x = x.flatten(2) # shape: (Batch, embed_dim, T'*H'*W')

        # Transpose to match the standard Transformer expectation: (Batch, Sequence_Length, Embed_Dim)
        x = x.transpose(1, 2)

        return x

# Example execution simulating a compressed video latent
batch_size = 2
latent_channels = 4

# Synthetic latent: the raw video duration depends on the VAE temporal stride.
video_latent = torch.randn(batch_size, latent_channels, 16, 32, 32)

patcher = SpacetimePatchEmbed(in_channels=latent_channels, embed_dim=1152, patch_size=(2, 2, 2))
tokens = patcher(video_latent)

print(f"Input latent shape: {video_latent.shape}")
print(f"Output token sequence shape: {tokens.shape}")
# Sequence length = (16/2) * (32/2) * (32/2) = 8 * 16 * 16 = 2048 tokens
```

## 2. 어텐션의 연결과 비용

폭 $d$ 인 토큰 $n$ 개에 대한 밀집 어텐션 코어의 연산량은 $O(n^2d)$ 이며 투영에는 $O(nd^2)$ 가 추가됩니다. 점수 행렬을 명시적으로 저장하면 제곱에 비례하는 메모리가 필요하지만, 융합된 정확 어텐션 커널은 전체 행렬을 저장하지 않을 수 있습니다. 분산 어텐션은 연산과 통신을 나누며 필요한 산술 연산 자체를 없애지는 않습니다.

- **공간 어텐션** 은 한 프레임 안의 위치를, **시간 어텐션** 은 시간에 걸친 위치를 연결합니다. 두 층을 교차 배치하면 정보 전달 범위가 넓어집니다. 한 층의 마스크가 전체 네트워크의 수용 영역은 아닙니다.
- **전체 어텐션** 은 모든 패치 사이의 정보 교환을 허용합니다. 연결할 수 있다는 사실이 유용한 추적이나 물리적 일관성을 학습했다는 뜻은 아닙니다.
- **희소 어텐션** 은 일부 연결을 제거해 연산을 줄입니다. 움직임, 가림, 긴 영상에서 품질을 평가해야 합니다. 한 분포에서 효율적인 패턴이 다른 분포에서는 필요한 근거를 제거할 수 있습니다.

아래 인터랙션은 인과 마스크가 없는 비디오 잡음 제거 모델의 연결을 보여 줍니다. 학습된 어텐션 가중치나 실시간 인과적 비디오 모델을 나타내지 않습니다.

## 3. 잡음 제거 모델에 조건 전달하기

DiT는 잡음이 섞인 잠재 토큰을 Transformer 블록으로 처리합니다. [[4]](#ref-4) 조건은 적응형 정규화, 교차 어텐션 또는 이어 붙인 토큰을 통해 전달할 수 있습니다. 적응형 정규화에서는 조건 네트워크가 정규화된 활성값의 스케일과 이동량을 만듭니다. 어떤 조건을 사용하는지는 구조마다 다릅니다.

FullDiT는 작업 조건을 하나의 시퀀스에서 결합합니다. [[2]](#ref-2) 이를 통해 조건 사이의 상호작용을 학습할 수 있지만, 모든 조건 충돌을 없애거나 동기화된 움직임을 보장하지는 않습니다. 토큰 연결은 시퀀스 연산량을 늘립니다. 모듈성이나 제한된 적응 예산이 중요하다면 별도의 어댑터가 적합할 수도 있습니다. 같은 조건과 자원 제한 아래에서 비교해야 합니다.

## 4. 보기 좋은 영상과 시뮬레이터의 보장은 다릅니다

가려진 물체가 다시 나타나더라도 시스템이 명시적이고 지속적인 물체 상태를 관리한다는 증거는 아닙니다. 움직임이 자연스러워 보이면서도 충돌, 개수, 보존 법칙은 틀릴 수 있습니다. Sora 보고서도 시뮬레이션의 한계를 설명합니다. [[1]](#ref-1) 물리적 일관성은 구조의 필연적 결과가 아니라 검증할 행동으로 다루어야 합니다.

엔지니어링 평가에서는 모델·체크포인트, 오토인코더, 스케줄러, 단계 수, guidance, 해상도, 길이, 시드와 조건을 고정합니다. 평가 장면과 그 변형은 학습에서 격리합니다. 가림과 재등장, 카메라 이동, 물체 개수, 접촉, 빠른 움직임, 글자, 상충하는 제어를 포함합니다. 세부 항목별 실패와 사람 평가의 일치도를 보고해야 합니다. 잘 나온 영상 하나는 성공률이 아닙니다.

최대 메모리, 첫 미리보기까지의 시간, 전체 생성 지연, 사용 가능한 결과의 비율과 그 결과당 비용을 측정합니다. 여러 시드로 반복하고 실패한 결과도 보존합니다. 채점 기준이 실제로 검사하는 물리적 속성을 명시합니다. 학습된 비디오 생성기와 행동 조건부 월드 모델은 표현을 공유할 수 있지만 필요한 검증은 다를 수 있습니다.

## 5. 실무적 정리

보존할 세부 정보와 영상 길이의 예산에 맞춰 압축률과 패치 크기를 선택합니다. 그다음 같은 품질·실행 조건에서 어텐션과 조건 처리 방식을 비교합니다. 공개 시연은 가설의 출발점이지만, 공개되지 않은 학습 세부 사항은 여전히 미공개입니다. 다음 절에서는 제품의 이용 가능 여부와 제공자의 주장을 이 기초 원리와 구분합니다.
