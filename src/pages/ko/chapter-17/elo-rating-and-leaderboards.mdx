# 17.3 Elo 평점 및 리더보드 (Elo Rating & Leaderboards)

네 사람이 이름을 가린 두 모델의 답을 비교합니다. 두 사람은 A를, 나머지 두 사람은 B를 선호했습니다. 한 담당자는 투표가 들어온 순서대로 평점을 갱신하고, 다른 담당자는 같은 파일을 거꾸로 읽습니다. 두 사람이 서로 다른 모델을 1위로 꼽을 수 있을까요?

한 표가 들어올 때마다 Elo 평점을 갱신하면 가능합니다. 아래 그림은 같은 두 모델과 같은 네 표를 사용합니다. A가 두 번 연속 이기고 나면 그다음 패배가 평점에 얼마나 크게 반영되는지 살펴보세요.

<a id="메커니즘-크라우드소싱-기반의-듀얼-crowdsourced-duels"></a>

## 사람의 한 표는 무엇을 기록할까?

평가자가 같은 질문에 대한 익명의 두 답을 읽고 A, B, 무승부 중 하나를 고릅니다. 그 표는 해당 질문에서 어느 답을 더 좋아했는지를 기록합니다. 사실이 틀려도 글이 매끄러운 쪽이 표를 받을 수 있습니다. 초기 Chatbot Arena 연구는 이런 방식으로 이름을 가린 답을 비교했습니다 [[2]](#ref-2).

먼저 두 번 이긴 A는 1530.5점까지 올랐다가 1494.7점으로 끝나 B보다 뒤처집니다. 먼저 두 번 지면 A는 1505.3점으로 끝나 B를 앞섭니다. 마음을 바꾼 평가자는 한 명도 없습니다. 매번 다음 표를 예상하는 기준이 달라졌습니다.

## Elo의 수학

Elo는 두 상대의 평점 차이로 한쪽이 얻을 기대 점수를 구합니다 [[1]](#ref-1).

### 1. 기대 점수 (Expected Score)

평점이 $R_A$ 와 $R_B$ 인 두 모델이 주어졌을 때, 모델 A의 기대 점수는 로지스틱 곡선을 사용하여 계산됩니다:

$$E_A = \frac{1}{1 + 10^{(R_B - R_A)/400}}$$

마찬가지로 모델 B의 기대 점수는 다음과 같습니다:
$$E_B = \frac{1}{1 + 10^{(R_A - R_B)/400}}$$

무승부를 반 점으로 처리하면 $E_A=P(\text{A의 승리})+0.5P(\text{무승부})$ 입니다. 평점 차이 400점은 기대 점수 약 0.91에 해당합니다. 무승부가 없는 경우에만 이를 약 91%의 승률로 읽을 수 있습니다. 척도 400과 기준 평점은 관례이므로 서로 다른 리더보드의 점수를 직접 비교하지 않습니다.

### 2. 평점 업데이트 (Rating Update)

듀얼 후, 실제 점수 $S_A$ 와 기대 점수 $E_A$ 를 기반으로 평점이 업데이트됩니다:

$$R'_A = R_A + K(S_A - E_A)$$

여기서 $S_A$ 는 실제 한 표의 점수입니다. 이기면 1, 비기면 0.5, 지면 0입니다. $K$ 는 한 표에 얼마나 크게 반응할지를 정합니다. B의 평점은 A의 변화량만큼 반대로 움직여 둘의 합은 일정합니다.

A가 먼저 두 번 이기면 A는 1530.53점, B는 1469.47점입니다. 다음 표에서 A의 기대 점수는 약 0.587입니다. 이제 지면 $32(0-0.587)$, 약 18.8점을 잃습니다. 첫 표에서 졌을 때 잃는 16점보다 큽니다. Python 표준 라이브러리로 네 표를 다시 계산해 봅시다. 반올림은 화면에 표시할 때만 합니다.

```python
def replay(votes, k=32):
    a = b = 1500.0
    path = [a]
    for vote in votes:
        expected = 1 / (1 + 10 ** ((b - a) / 400))
        change = k * (vote - expected)
        a += change
        b -= change
        path.append(a)
    return path

for votes in ([1, 1, 0, 0], [0, 0, 1, 1]):
    print([round(rating, 1) for rating in replay(votes)])
```

### Bradley–Terry로 네 표를 한꺼번에 읽으면

두 모델의 버전이 고정돼 있고 네 표의 가중치가 같다고 합시다. 무승부가 없는 두 모델의 Bradley–Terry 모형에서 A가 이길 확률의 추정값은 $2/4=0.5$입니다. 어느 순서로 읽어도 **추정 평점 차이는 0** 입니다. 두 평점에 같은 수를 더해도 확률이 같으므로 기준 모델의 평점을 고정하거나 전체 평점의 합에 제약을 둡니다. 모델이 여럿이고 서로 한 번도 맞붙지 않은 두 집단이 있다면, 이 표만으로는 집단 간 평점 차이를 정할 수 없습니다. 한쪽이 전승하면 정규화 없는 최대우도 추정값이 유한하게 존재하지 않을 수도 있습니다.

Arena 팀은 2023년 12월에 리더보드를 온라인 Elo에서 Bradley–Terry 추정으로 바꾼 이유를 설명했습니다. 발표된 점수를 재현하려면 표를 한 장씩 반영했는지, 전체 표에 모형을 맞췄는지부터 확인해야 합니다 [[3]](#ref-3).

### 리더보드 숫자를 읽을 때의 함정

여기서는 네 표만 관측했습니다. 추정 차이가 0이어도 다음 평가자들이 어떻게 투표할지는 여전히 불확실합니다. 두 모델 간 차이의 불확실성을 함께 제시하세요. 같은 사람이나 같은 질문에서 표가 여러 개 나왔다면 불확실성을 추정할 때 그 묶음을 유지합니다. 무승부 처리 방법, 질문과 모델 버전, 평가자를 어떻게 골랐는지도 기록합니다 [[4]](#ref-4).

## PyTorch로 서로 다른 모델 쌍을 한 번에 갱신하기

같은 두 모델에 들어온 네 표는 순서대로 계산합니다. 반면 **서로 독립적인 모델 쌍** 은 벡터 연산 한 번으로 갱신할 수 있습니다. 아래에서 각 행의 두 모델은 다른 행에 등장하지 않습니다. 첫 행은 A의 승리, 두 번째 행은 무승부입니다.

이 코드는 한 쌍당 한 표만 반영합니다. 실제 리더보드에는 지속적으로 쓸 모델 식별자, 반복 투표 처리 방침, 갱신 순서가 필요합니다.

```python
import torch

def compute_batch_elo_update(ratings_a, ratings_b, outcomes, k_factor=32.0):
    expected = 1 / (1 + 10 ** ((ratings_b - ratings_a) / 400))
    change = k_factor * (outcomes - expected)
    return ratings_a + change, ratings_b - change

a = torch.tensor([1500.0, 1500.0])
b = torch.tensor([1500.0, 1500.0])
print(compute_batch_elo_update(a, b, torch.tensor([1.0, 0.5])))
# (tensor([1516., 1500.]), tensor([1484., 1500.]))
```

## 제품에서 평점과 함께 확인할 것

환불 안내 메일을 쓰는 모델을 고른다고 합시다. 환불 금액을 틀렸는데도 친절한 답변이 표를 더 받을 수 있습니다. 선호 투표와 함께 금액의 정확성을 검사하고, 후보 모델을 같은 구성의 사례로 평가하세요. 환불 정책이나 배포 모델이 바뀌었을 때 영향받은 비교를 찾을 수 있도록 모델과 프롬프트 버전도 기록합니다.
