# 17.6 상용·오픈 웨이트 모델 벤치마크

새 모델 출시는 순위표의 이름만 바꾸지 않습니다. 다운로드할 아티팩트, 라이선스, 프롬프트 인코딩, 추론 예산, 가격 구간, API 별칭이 가리키는 리비전도 달라질 수 있습니다. 이 조건을 먼저 확인한 뒤 전체 워크플로를 측정해야 합니다.

**2026-11-15 기준.** 전체 출시 목록이 아닌 32개 프로필의 정적 스냅샷입니다. 날짜는 출시, 가중치 공개, 확인한 아티팩트 리비전 중 명시된 이정표이며 모두 최초 출시일인 것은 아닙니다. 공개 저장소가 생성된 날짜만으로 가중치 공개일을 확정할 수 없습니다. 이후 출판·배포 시 출처를 다시 확인하세요.

## 1. 벤치마크 버전이 바뀌면 측정도 달라집니다

Artificial Analysis의 현재 **Intelligence Index v5.0.1**은 지식 업무, 코딩, 과학, 일반 과업의 9개 평가를 포함합니다 [[1]](#ref-1). 이 장은 10월의 v4.3.2 값을 전부 새 기준으로 교체했습니다. 두 버전 사이의 점수 변화가 같은 가중치의 성능 향상이나 저하를 뜻하지는 않습니다. 이전 점수를 새 점수에서 빼서 성능 추세로 해석하면 안 됩니다.

평가 대상에는 추론 강도, fallback, 실행 프레임워크, 도구 접근, 토큰·문맥 예산, 샘플링, 채점기가 포함됩니다. 동일 연산량 실험이 아닙니다. 지수는 정확도 백분율이 아니며 문맥 한도는 검색 정확도가 아닙니다. 빈 값은 **대응하는 리비전·평가 방식으로 확인하지 못한 값** 이고 0점이 아닙니다.

## 3. 새 출시에서 읽어야 할 변화

### 호스팅 접근과 가중치 공개는 별도 이정표입니다

**Kimi K3.1 Pro**의 공개 가중치 파일을 이제 확인할 수 있습니다. 카드는 전체 2.8T·활성 104B, KDA/gated sparse attention 혼합, 양자화 인지 학습 형식을 명시합니다. 표의 날짜는 확인한 11월 5일 아티팩트 리비전입니다. 이전의 ‘가중치 공개 예정’ 판단은 바뀌지만 전체 학습 데이터 혼합이나 호스팅·로컬 동등성까지 확인된 것은 아닙니다. Highspeed에는 별도 검증하지 않은 사양을 복사하지 않았습니다 [[49]](#ref-49) [[50]](#ref-50) [[51]](#ref-51) [[52]](#ref-52).

**Mistral Large 4**는 10월 프리뷰 이후 가중치가 공개됐습니다. 모델 카드와 현재 문서는 세분화된 멀티모달 MoE를 명시합니다. Mistral Ecosystem Open-Weight License는 Model-as-a-Service 사업에 별도 계약을 요구하므로 가중치 공개가 무제한 호스팅을 뜻하지 않습니다. 현재 AA high 평가는 이전 프리뷰 결과와 구분합니다 [[24]](#ref-24) [[25]](#ref-25) [[26]](#ref-26) [[27]](#ref-27).

**Inkling 2 Small**도 호스팅 출시 이후 Apache 2.0 가중치를 공개했습니다. 카드는 전체 594B·활성 17B와 MXFP8/NVFP4 혼합 아티팩트를 명시합니다. vLLM 통합 문서는 내장 초안 헤드와 하드웨어별 최적화를 설명합니다. 활성 연산량과 패킹 용량만으로 전체 상주 가중치, KV 상태, 시각 처리, 임시 버퍼를 계산할 수 없습니다. 초안 헤드의 속도는 실제 배포 조건에서 측정해야 합니다 [[65]](#ref-65) [[66]](#ref-66) [[67]](#ref-67) [[68]](#ref-68).

### 범용 설정과 제한 접근 설정은 별도로 평가합니다

**GPT-6.1 Terra**는 텍스트·이미지 입력과 텍스트 출력의 새로운 선택지입니다. 공식 문서는 1,050,000토큰 문맥, 128,000토큰 출력 한도, 추론 강도를 구분하며 도구 호출에 Responses가 필요하다고 명시합니다. 표준 단가는 100만 토큰당 입력 \$1·출력 \$5이고 캐시·장문·서비스 등급 조건은 별도입니다. 아키텍처, 파라미터 수, 학습 혼합은 미공개입니다 [[60]](#ref-60) [[61]](#ref-61).

Anthropic은 **Claude Fable 5.2**와 **Mythos 5.2**의 기본 모델은 같고 안전장치·접근 조건이 다르다고 설명합니다. Mythos에는 검증 프로그램을 통한 접근이 필요합니다. 따라서 Fable의 측정값을 Mythos에 옮기지 않았습니다. Fable의 표준 입력/출력 단가 \$8/\$40은 고속 모드 \$16/\$80과 다르고, 과업 비용에는 추론 길이와 fallback도 영향을 줍니다. 제공사의 장기 과업 시연은 그 시스템의 사례이지 일반적인 신뢰성 보장이 아닙니다 [[62]](#ref-62) [[63]](#ref-63) [[64]](#ref-64).

### 제품군 이름보다 파라미터 계산 범위를 확인합니다

**Qwen3.8 Flash Next** 카드는 본체 125B·활성 6B 외에 n-gram 임베딩 51B와 MTP 4B를 구분합니다. Gated DeltaNet, 블록 희소 QSA, 게이트가 있는 잔차 스트림을 결합합니다. 기본 문맥 262,144는 확장 설정 및 호스팅 Flash 서비스와 다릅니다. 표의 11월 7일은 확인한 리비전이며 새 출시일이라는 주장이 아닙니다 [[69]](#ref-69) [[70]](#ref-70) [[71]](#ref-71).

**GLM-5.3 Flash**는 GLM-5.3을 빠르게 서빙하는 설정이 아니라 별도로 학습한 멀티모달 기반 모델입니다. 카드는 전체 320B·활성 18B와 MIT 가중치를 명시합니다. 10월 15일 리비전은 아키텍처 비교를 보완하기 위해 넣었으며 11월 신작으로 소개하는 것이 아닙니다 [[72]](#ref-72) [[73]](#ref-73) [[74]](#ref-74). 표의 소형·도메인 특화 모델도 다른 제품군 구성원의 벤치마크나 구조를 그대로 물려받지 않습니다.

## 4. 누락을 채우지 않고 장단점 탐색하기

지표·축·제공사를 선택하면 두 축 값을 모두 확인한 모델만 표시됩니다. 선택 목록과 상세 정보도 필터를 따릅니다. 빈 그래프는 유효한 결과이며 가나다·알파벳 순 선택 목록은 순위가 아닙니다.

토큰 가격 축은 100만 토큰당 캐시 없는 단가의 예시 혼합 $(3p_{in}+p_{out})/4$를 사용합니다. 캐시 쓰기·읽기, 도구, 모달리티 요금, 장문 구간, 출력 길이 차이는 제외합니다. AA 자체 혼합 단가나 관측 과업 비용과는 다릅니다. 현재 Google Argon 도입 가격은 11월 30일에 끝나므로 이후 비용을 계산할 때 다시 확인해야 합니다 [[16]](#ref-16) [[17]](#ref-17) [[18]](#ref-18) [[19]](#ref-19).

## 5. 후보 목록을 릴리스 결정으로 연결하기

하나의 보편적 승자보다 품질·비용·지연·문맥·개방성·안전성의 파레토 관점으로 선택합니다. 도구, 권한, 실행 프레임워크, 추론 강도, 재시도, 입출력 한도, 채점기를 고정하고 같은 비공개 과업을 평가하세요. 짝지은 불확실성, 언어·도메인별 결과, 기본 능력 보존, 형식·도구 정확성, 안전성, 꼬리 지연, 오류율, 성공한 워크플로당 비용을 보고합니다. 평균이 개선돼도 핵심 집단이 실패하면 릴리스를 막아야 합니다.

가중치/API 리비전, 토크나이저·템플릿, 양자화, 런타임, 생성 설정, 도구 스키마, 안전 정책을 하나의 불변 아티팩트 묶음으로 유지합니다. 호스팅과 로컬 버전은 따로 평가합니다. 제한된 권한으로 카나리 배포하고 정상 경로를 유지하며 캐시 상태와 대기 중인 외부 작업까지 롤백을 연습하세요. 형식이 정해진 결정 모델에는 별도 보정·선택적 위험 평가가 필요합니다. [16.7절](/ko/chapter-16/decision-models-and-selective-prediction)을 참고하세요.
