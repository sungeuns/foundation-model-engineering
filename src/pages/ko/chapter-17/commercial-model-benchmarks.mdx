# 17.6 상용·오픈웨이트 모델 벤치마크

모델 공개는 순위표 외에도 접근·라이선스·프롬프트 인코딩·가격·출력 예산·고정된 API 별칭의 실제 리비전을 바꿀 수 있습니다. 익숙한 이름을 바로 교체할 수 있는 모델로 취급하기 전에 이런 계약부터 평가해야 합니다.

**2026-10-18 기준.** 실시간 순위표가 아닌 날짜가 있는 과거 스냅샷입니다. 아래 출처를 이번 검토에서 다시 확인했으며 이후 게시·도입 전에는 **반드시 다시 검증** 해야 합니다. 이 절은 10월 13일 스냅샷을 갱신했습니다. 선택한 10월 날짜에는 접근 확대·가중치 공개·체크포인트 갱신이 포함되며 모두 최초 발표일이라는 뜻은 아닙니다.

## 1. 모델명보다 평가한 시스템을 읽는다

아래 지수는 평가 10개로 정의된 Artificial Analysis Intelligence Index **v4.3.2**를 사용합니다 [[1]](#ref-1). 추론 강도와 fallback도 결과의 일부입니다. 추론 설정이나 제공사 라우팅이 다르면 **동일 연산량·가중치만의 통제 비교가 아닙니다**. 같은 과제·도구·지연·예산 제약의 비공개 평가 후보를 고르는 데 활용해야 합니다.

세부 추론 강도를 출처가 제시하지 않으면 그대로 미공개로 표시합니다. 임의로 채우지 않습니다. 호스팅 Step 5 프로필은 새 가중치 공개보다 앞선 것이며, 9월 DeepSeek 프로필은 10월 17일 리비전의 검증된 평가가 아닙니다. 리비전 동등성을 모르면 점수를 복사하지 말고 다시 시험해야 합니다.

## 3. 지난 검토 이후 달라진 점

### 가중치 공개는 별도의 이정표다

Beam은 10월 5일 발표 이후 10월 16일 가중치를 공개했습니다 [[26]](#ref-26). 카드는 BF16·FP8·NVFP4 아티팩트, 수정된 Harmony 대화 형식, 아직 예정인 전체 기술 보고서를 구분합니다 [[27]](#ref-27). NVFP4 파일의 패킹 텐서 수를 다른 모델 아키텍처의 파라미터 수로 해석하면 안 됩니다.

Muse Spark Open은 Muse Model License 아래 공개한 승인형 다운로드 체크포인트입니다. 카드는 추가 안전 사후 학습을 호스팅 Spark 계열과 구별합니다 [[33]](#ref-33). 오픈웨이트가 Apache 라이선스·무제한 다운로드·전체 데이터 공개를 뜻하지는 않습니다. Step 5 Preview도 자체 라이선스의 BF16·저정밀 아티팩트를 공개했습니다. 이름의 **Preview** 때문에 가중치가 여전히 예정이라고 판단하면 안 됩니다 [[39]](#ref-39). 실제 라이선스와 정확한 아티팩트 리비전을 검토해야 합니다.

### 호스팅 모델과 접근 확대도 구분한다

Muse Wonder는 Meta API와 Muse Code, Wonder Full은 Muse Code 구독으로 제공합니다 [[29]](#ref-29). 발표문은 파라미터 수나 전체 학습 레시피를 공개하지 않습니다. API 모델의 토큰 가격을 구독 전용 변형에 옮겨 넣지 않습니다.

Gemini 4 Argon의 API 접근은 10월 13일 확대됐습니다. 현재 문서는 입출력 통합 윈도우와 동기·long-decode 출력 한도를 구분합니다 [[17]](#ref-17). 표준 유료 단가는 **2026-11-30까지** 100만 토큰당 입력 \$2·출력 \$10이고, **2026-12-01부터** \$4·\$20입니다 [[18]](#ref-18). 만료를 비용 모델에 반영해야 합니다. 도입 가격이나 가장 큰 출력 허용량을 영구적·보편적 계약으로 취급하면 안 됩니다.

### 같은 별칭이 다른 모델을 가리킬 수 있다

10월 17일 DeepSeek 변경 기록은 API 호출 방식·가격 변경 없이 `deepseek-flash`를 V4.1 Flash 1017로 갱신했다고 명시합니다 [[42]](#ref-42). 카드는 명시한 harness의 개선을 보고하고 Jinja 템플릿 대신 프로토콜을 인식하는 인코딩을 제공합니다 [[41]](#ref-41). 제공사 결과이지 새 AA 측정값이 아닙니다. 체크포인트·인코더 리비전을 고정하고 도구·이미지 인코딩을 보존하며, 갱신한 별칭을 canary로 도입하기 전에 전체 시스템을 비교합니다.

### 작은 저장 용량이 배포 보장은 아니다

Nemotron 3.5 Super VL·Bolt는 상태 공간·attention·MoE를 결합한 비전 언어 구조를 공개합니다. Bolt의 IQ2 QAT와 24GB 패킹 모델 목표에는 호환 커널과 별도 상태·workspace 계산이 필요합니다 [[37]](#ref-37). 모델명으로 장문·동시 요청에 남는 메모리를 알 수는 없습니다. 13.5절은 명목 비트 수와 실제 수용량을 구분합니다.

Mistral Large 4는 발표문에서 여전히 공개 API 프리뷰이며 가중치는 10월 중 추후 공개 계획입니다 [[24]](#ref-24). Claude도 설정별 가격 조건을 보존해야 합니다. 개요의 Haiku 단가는 “from”으로 한정됩니다 [[43]](#ref-43). 이런 한정을 지우고 최저 가격이나 예정 공개로 빈칸을 채우지 않습니다.

## 4. 누락값을 만들어내지 않고 프로필을 탐색한다

그래프는 선택한 지표·축의 값이 모두 있는 항목만 표시합니다. 모델 선택 목록은 이름순이며 보편적 품질 순위가 아닙니다. 토큰 단가의 예시 혼합은 $(3p_{in}+p_{out})/4$이며 $p_{in}$, $p_{out}$는 100만 토큰당 캐시 없는 표준 입출력 가격입니다. 가상의 3:1 혼합이고 캐시 쓰기·적중·도구·이미지 및 오디오·장문 구간·추론 출력 길이를 제외합니다. 문서화된 표준 가격만 넣었습니다.

문맥 지표는 선언된 한도이며 장문 추론의 측정 품질이 아닙니다. 출처별 입출력 의미를 따로 확인해야 합니다. 비교할 수 없는 제공사나 누락 측정값으로 속도 곡선을 만들지 않습니다.

## 5. 프로덕션 평가 기준

같은 비공개 과제에서 scaffold·도구·추론 강도·입출력 예산·재시도·grader를 고정해 후보 프로필을 평가합니다. 지원 언어·형식·권한·안전·능력 보존·꼬리 지연·성공당 비용·오류율 slice를 추가합니다. 로컬 양자화 체크포인트는 호스팅 결과와 독립적으로 평가합니다. 짝지은 불확실성이나 정당화된 표본 수를 사용하고 평균이 좋아져도 중요한 slice가 실패하면 출시를 막습니다.

모델·토크나이저 또는 인코딩 도구·템플릿·런타임·도구 스키마·생성 설정·정책 해시를 하나의 아티팩트 묶음으로 유지합니다. 제한된 권한에서 canary를 수행하고 정상 경로를 보관하며 캐시 상태와 대기 중인 도구 효과까지 롤백을 연습합니다. 새 공개는 평가의 계기이지 배포 지시가 아닙니다.
