# 17.6 상용·오픈웨이트 모델 벤치마크

모델 공개는 순위표 외에도 접근·라이선스·프롬프트 인코딩·가격·출력 예산·고정된 API 별칭의 실제 리비전을 바꿀 수 있습니다. 익숙한 이름을 바로 교체할 수 있는 모델로 취급하기 전에 이런 계약부터 평가해야 합니다.

**2026-10-25 기준입니다.** 실시간 순위가 아닌 날짜가 고정된 과거 스냅샷입니다. 공개 출처와 AA 프로필을 이번에 확인했으며 추후 출판·도입 전에는 **다시 검증** 해야 합니다. 날짜는 발표·접근 확대·가중치 공개·명시한 아티팩트 리비전 중 선택한 이정표이며 모두 최초 출시일을 뜻하지는 않습니다.

## 1. 평가된 시스템 읽기

지수는 평가 10개로 구성된 Artificial Analysis Intelligence Index **v4.3.2** 입니다 [[1]](#ref-1). 추론 강도·fallback·scaffold·도구·샘플링·문맥·채점기·리비전이 결과의 일부입니다. 서로 다른 프로필은 동일 계산량이나 가중치만 통제한 비교가 아닙니다. 지수는 백분율이 아니며 선언한 문맥 한도가 장문 추론 정확도도 아닙니다.

표는 선택한 26개 프로필이며 모든 출시의 목록은 아닙니다. AA가 추론 강도를 명시하지 않으면 미공개로 남깁니다. 새 체크포인트에 기반 모델의 점수를 옮기지 않고 가격 누락을 무료로 해석하지 않습니다. 품질·비용·지연·문맥·개방성·안전성의 파레토 경계에서 후보를 고르고 동일한 운영 제약의 비공개 평가로 검증해야 합니다.

## 3. 10월 19–25일 공개가 바꾸는 것

### API 제공과 가중치 공개는 다른 사건

MiniMax M3.1 Flash는 10월 19일 호스팅 제품에서 출시됐고, 이제 공식 저장소에 실제 가중치 파일이 있습니다. 23일 리비전을 별도 기록했습니다. 카드는 MiniMax Community License 아래 전 계층 희소 어텐션·양자화 인지 학습·DSpark draft head를 설명합니다 [[44]](#ref-44) [[45]](#ref-45). 카드의 파라미터는 전체 약 428B·활성 23B입니다. Hub의 패킹된 텐서 수를 아키텍처 파라미터 수로 대체하면 안 됩니다. 표준 출시 가격은 백만 토큰당 입력 \$0.15·출력 \$0.60이며 캐시 적중은 별도입니다. Draft head를 보편적인 속도 배수로 해석하지 말고 서빙 레시피를 확인하세요.

Kimi K3.1 Pro와 Highspeed는 호스팅 채널에서 사용할 수 있습니다. 10월 24일 기술 글은 Pro 전체 가중치를 **11월 4일까지** 공개한다고 약속합니다. Highspeed의 별도 가중치 아티팩트는 확인되지 않아 둘 다 공개 완료로 표시하지 않습니다 [[48]](#ref-48). “3T-class”는 제공사 표현이며 글에서 정확한 전체·활성 파라미터와 전체 학습 혼합은 미공개입니다. 호스팅 점수가 이 공백을 채우지 않습니다. Highspeed의 2~3배 속도 주장도 제공사 간 지연 그래프에 넣지 않습니다. 별도 확인되지 않은 문맥 한도·가격·지수는 미공개로 유지합니다.

Mistral Large 4는 여전히 API 프리뷰와 10월 말 가중치 계획입니다 [[24]](#ref-24). 예정일이 가까워졌다는 사실은 공개 완료의 근거가 아닙니다. 반대로 Step 5 **Preview** 는 실제 가중치가 있습니다. 이름이 공개 상태를 정하지는 않습니다 [[39]](#ref-39).

다시 확인한 Mistral 변경 기록도 Large 4를 Public Preview로 표시하고 가중치는 공개 예정이라고 명시합니다 [[61]](#ref-61).

### 익숙한 이름 뒤의 리비전 고정

DeepSeek V4.1 Flash 1017에는 이제 자체 AA max 프로필이 있습니다. 지수 45·관측 과업 비용 \$0.26은 명시된 리비전의 독립 기록이며 9월 값을 빌린 것이 아닙니다 [[43]](#ref-43). 가변 API 별칭과 프로토콜 인지 인코딩에 대해서는 여전히 전환 검사가 필요합니다 [[42]](#ref-42).

Ling 3.1 Flash의 MIT 공개 카드는 KDA/gated-MLA 하이브리드와 전체 560B·활성 25B MoE를 명시합니다 [[50]](#ref-50). 표의 10월 20일은 확인한 아티팩트 리비전이며 최초 호스팅 출시일이 아닙니다. AA에는 별도의 **1019 호스팅 프로필** 도 있지만 공개 체크포인트와의 관계가 검증되지 않았습니다. 따라서 명시적으로 맞춘 기존 프로필의 41·\$1.01을 유지합니다 [[51]](#ref-51). 비슷한 이름의 높은 점수만으로 리비전 동등성이 성립하지 않습니다.

### 작은 메모리 목표는 특정 아티팩트의 조건

NVIDIA가 10월 23일 공개한 Bolt E4B 4GB는 하이브리드 Mamba/MoE Bolt 74B와 달리 Gemma-4-E4B 기반입니다. 카드는 전체 8B·유효 4B, OpenMDW-1.1, 입력·출력 각각 최대 64K를 명시합니다 [[58]](#ref-58) [[59]](#ref-59). 두 한도를 더해 통합 문맥이라고 주장하거나 이름으로 아키텍처를 추정하면 안 됩니다. “4GB” 목표는 임의의 문맥·동시성·음성 파이프라인 메모리를 확보해 주지 않습니다.

Smaug Nemotron 3.5 NVFP4는 실제 가중치가 공개된 OpenMDW-1.1 미세 조정 모델입니다. Abacus는 실제 서빙 형식으로의 반올림을 반영하는 적응을 설명합니다 [[55]](#ref-55) [[56]](#ref-56). 이는 부동소수점 어댑터뿐 아니라 **병합한 양자화 아티팩트** 를 검사해야 할 이유입니다. 제공사 개선 주장과 기반 모델 결과는 이 리비전의 AA 점수가 아닙니다. 13.5절은 명목 가중치 비트 외의 상태·작업 공간을 다룹니다.

Ling 3.0 Flash Sante는 MIT 의료 연구 체크포인트이며 카드는 전체 124B·활성 5.1B와 도메인 평가를 제시합니다 [[53]](#ref-53). 임상 검증이나 범용 능력의 보편적인 개선 근거는 아닙니다. 의료 벤치마크로 AA 값을 만들지 말고 도메인 검토와 적절한 과업 기준선을 사용하세요.

## 4. 누락값을 채우지 않는 프로필 탐색

지표·축·필터에 필요한 두 값이 모두 있는 항목만 표시합니다. 이름순 선택 목록은 보편적 순위가 아닙니다. 토큰 단가 점은 백만 토큰당 비캐시 표준 입력·출력 단가로 $(3p_{in}+p_{out})/4$ 를 계산한 예시입니다. 캐시 쓰기·적중, 도구, 모달리티, 장문 요금 구간, 출력 길이 차이는 제외합니다. 회사·축 조합이 비어도 누락값을 미공개로 유지합니다.

문맥 지표는 제공사별 의미를 보존합니다. Bolt E4B는 입력 한도이며 Gemini 4 Argon 계약은 통합 창입니다. 프로모션 가격에는 만료일도 있습니다. Google의 Argon 도입 가격은 11월 30일까지입니다 [[17]](#ref-17) [[18]](#ref-18). 비교 조건이 다른 속도를 섞어 곡선을 만들지 않았습니다.

## 5. 파이프라인과 판단 경계 평가

Jev·OpenAI Decisions·open d1·LemonDecider는 자유로운 답변 생성 대신 범위가 정해진 판단을 제공합니다. 선택지 확률·보정·선택 위험을 따로 평가해야 합니다. Decision Index는 생성 모델 AA 지수의 점이 아닙니다. [16.7절](/chapter-16/decision-models-and-selective-prediction)은 공개된 메커니즘·보류 정책·릴리스 게이트를 설명합니다.

생성이든 판단이든 scaffold·도구 권한·추론 강도·입출력 예산·재시도·채점기를 고정하고 같은 비공개 과업에서 평가하세요. 언어·도메인, 기반 역량 유지, 형식·도구, 안전성, 지연 꼬리, 검토 용량, 성공한 워크플로당 비용, 오류율 슬라이스를 포함합니다. 로컬 양자화는 호스팅 프로필과 별개로 검사해야 합니다. 대응 표본 불확실성이나 정당화한 표본 수를 사용하고 평균이 좋아져도 핵심 슬라이스 실패는 릴리스를 막아야 합니다.

가중치/API 리비전·토크나이저/인코딩·템플릿·보정과 판단 정책·런타임·도구 스키마·생성 설정·안전 정책 해시를 하나의 아티팩트 묶음에 둡니다. 제한된 권한으로 카나리하고 정상 경로를 남기며 캐시 상태·진행 중 효과까지 롤백을 연습하세요. 새 출시는 전체 시스템을 평가할 계기입니다.
