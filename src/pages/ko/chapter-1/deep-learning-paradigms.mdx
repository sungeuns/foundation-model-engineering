# 1.3 딥러닝의 세 가지 학습 방식

“연기는 좋았다. 그런데 줄거리는 아쉬웠다.” 이 영화평을 읽고 *글쓴이가 칭찬한 것은 무엇인가?* 라는 질문에 답하는 모델을 만들고 싶습니다. 영화평만 모으면 될까요? 아니면 누군가 질문마다 정답을 써 줘야 할까요? 필요한 자료는 모델에 어떤 일을 가르칠지에 따라 달라집니다.

## 무엇을 보고 배우는가

| 학습 방식 | 예시 한 건에서 얻는 정보 | 모델이 배우는 일 |
| --- | --- | --- |
| 자기지도 학습 | 영화평의 “줄거리는” 뒤에 실제로 “아쉬웠다”가 나옵니다. 원문 안에 정답이 있습니다. | 앞부분을 읽었을 때 실제로 뒤따른 단어의 확률을 높입니다. |
| 지도 미세 조정(SFT) | 영화평과 질문에 답안 “연기”를 붙여 줍니다. | 이 질문과 영화평을 받으면 예시 답안을 생성할 확률을 높입니다. |
| 강화 학습(RL) | 모델이 두 답 중 하나를 골라 봅니다. 이 예제의 채점기는 칭찬한 대상을 맞히면 1점, 틀리면 0점을 줍니다. | 답을 고르는 방식을 바꿔 앞으로 받을 보상의 기댓값을 높입니다. |

자기지도 학습과 지도 미세 조정은 둘 다 다음 토큰 예측 손실을 쓸 수 있습니다. 차이는 정답을 어디서 얻고 어느 위치를 채점하느냐에 있습니다. 원문으로 학습할 때는 뒤이어 나오는 단어 하나하나가 정답이 됩니다. 질의응답 예시로 학습할 때는 영화평과 질문을 읽게 하되 답안에 해당하는 토큰만 채점할 수 있습니다. [지도 미세 조정 절](../../chapter-9/sft-fundamentals/)에서 손실 마스크로 채점할 위치를 지정하는 방법을 다룹니다.

## 예상 밖의 단어가 나오면 손실은 얼마나 클까?

영화평마다 토큰 두 개만 남겨 봅시다. “연기는 좋았다”가 세 건, “연기는 아쉬웠다”가 한 건, “줄거리는 좋았다”가 한 건, “줄거리는 아쉬웠다”가 세 건입니다. 횟수로 예측하는 모델은 “연기는” 뒤에 “아쉬웠다”가 올 확률을 $1/4$로 잡습니다. 별도로 수집한 영화평에서 실제로 “아쉬웠다”가 나왔다면 이 토큰의 손실은 $-\ln(1/4)=1.386$ nat입니다. $\ln$은 자연로그입니다. 채점 대상 토큰마다 이 값을 구해 평균을 내면 다음 토큰 예측의 평균 교차 엔트로피를 얻습니다.

아래에서 **연기는 → 아쉬웠다** 를 선택한 뒤, 학습 자료에 “연기는 아쉬웠다”라는 별개의 영화평을 한 건 추가해 보세요. *같은* 토큰을 다시 채점해도 예측 확률은 $2/5$로 오르고 손실은 $0.916$ nat로 줄어듭니다. 첫 토큰을 **줄거리는** 으로 바꾸면 어떻게 될까요? “좋았다” 한 건, “아쉬웠다” 세 건은 그대로입니다. 실제 신경망에서는 여러 문맥이 파라미터를 공유하므로 학습 자료 한 건을 바꾸면 다른 문맥의 예측까지 달라질 수 있습니다.

아래 파이썬 코드에서 `acting`과 `plot`은 연기와 줄거리, `good`과 `weak`은 긍정과 아쉬움을 뜻합니다. CPU에서 영화평 여덟 건을 한 번 읽습니다. 각 영화평에서 이웃한 토큰 쌍 하나를 세고, 다음 영화평에 들어가면 새로 짝을 짓습니다. 특수 토큰이나 패딩을 붙이지 않고 옵티마이저도 쓰지 않습니다. 이 모델은 토큰 표기와 횟수표만 저장하면 같은 예측을 복원할 수 있습니다.

```python
from collections import Counter
from math import inf, log

reviews = ([("acting", "good")] * 3 + [("acting", "weak")]
           + [("plot", "good")] + [("plot", "weak")] * 3)

def train(records):
    counts = Counter()
    for record in records:
        counts.update(zip(record, record[1:]))
    return counts

def score(counts, first, observed):
    total = sum(n for (left, right), n in counts.items() if left == first)
    if total == 0:
        raise ValueError(f"Unseen first token: {first}")
    probability = counts[first, observed] / total
    return probability, -log(probability) if probability else inf

for records in (reviews, reviews + [("acting", "weak")]):
    probability, loss = score(train(records), "acting", "weak")
    print(f"{probability:.2f} {loss:.3f}")
```

출력은 차례로 `0.25 1.386`, `0.40 0.916`입니다. 처음 보는 단어로 시작하면 횟수표에 근거가 없어 확률 분포를 구할 수 없습니다. 첫 단어를 전에 봤더라도 한 번도 이어진 적 없는 단어의 예측 확률은 0이고 손실은 무한대입니다. [디코더 전용 모델 예제](../../chapter-4/decoder-only/#shifted-target-example)에서는 긴 문장을 넣었을 때 예측 위치와 정답 토큰을 어떻게 맞추는지 확인할 수 있습니다.

## 다음 말을 잘 맞히면 질문에도 잘 답할까?

“연기는 아쉬웠다”라는 문장의 예측 손실이 낮아져도 독자가 칭찬한 대상을 고르는 능력은 별도로 확인해야 합니다. 평가용 영화평 두 건을 준비해 보세요. 첫 글은 연기를 칭찬하고 줄거리를 아쉬워합니다. 두 번째 글에서는 두 평가를 맞바꿉니다. 어느 글에나 “연기”라고 답하는 모델도 두 건 중 한 건은 맞힙니다. 결과를 칭찬 대상별로 기록하고, 새 모델이 이전에 맞히던 대상을 놓치면 기존 모델을 유지하세요. 이 두 문장으로 확인할 수 있는 것은 모델이 무조건 한쪽을 고르는지까지입니다. 실제 배포를 결정할 때는 독자가 쓰는 표현과 다루는 소재를 반영한 별도의 평가 자료가 필요합니다.

실제 연구에서도 학습 목표가 다르면 같은 원문을 다르게 씁니다. BERT는 앞뒤 문맥으로 선택된 위치의 토큰을 예측하고, GPT-3는 앞선 문맥으로 다음 토큰을 예측합니다. 두 방식 모두 원문에서 정답을 얻습니다. [[1]](#ref-1) [[3]](#ref-3) InstructGPT는 사람이 쓴 답안으로 지도 미세 조정을 한 뒤, 사람들이 두 답을 비교한 결과로 보상 모델을 학습했습니다. 이어서 새로 생성한 답에 보상 모델이 매긴 점수를 활용해 PPO로 정책을 조정했습니다. [[2]](#ref-2) DPO는 저장된 선호 답과 비선호 답의 확률을 기준 정책과 비교해 직접 학습합니다. 별도의 보상 모델을 학습하거나 그 과정에서 매번 답을 새로 생성할 필요가 없습니다. [[4]](#ref-4)

<summary>Quiz 2: “연기는 아쉬웠다”를 학습 자료에 한 건 추가하면 “연기는 좋았다”의 손실은 어떻게 될까요?</summary>

</details>

<details>
<summary>Quiz 3: 질의응답 평가에 줄거리를 칭찬하는 영화평도 넣는 이유는 무엇일까요?</summary>
*연기를 칭찬하는 글만 있으면 본문을 무시하고 늘 “연기”라고 답해도 만점을 받습니다. 두 평가를 맞바꾸면 소재는 유지하면서 정답만 바꿔 이 문제를 드러낼 수 있습니다.*
</details>

<details>
<summary>Quiz 4: 이미 누군가 두 답의 선호 순위를 매겼습니다. InstructGPT의 후속 학습 중 DPO에서 생략할 수 있는 과정은 무엇일까요?</summary>
*InstructGPT에서는 비교 결과로 별도의 보상 모델을 학습하고 PPO 도중 새로 생성한 답을 채점합니다. DPO는 저장된 두 답과 기준 정책을 사용해 정책을 직접 갱신합니다.*
