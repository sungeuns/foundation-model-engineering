# 4.4 Hybrid & Prefix LM

A translation service receives the whole source sentence before it writes the first word of the translation. While reading the source, a word near the end can clarify a word near the beginning. While writing the translation, each decision has to use only what the service has received or written so far. A **prefix language model** can enforce both rules in one stack of Transformer layers. [[2]](#ref-2)

<a id="the-metaphor-the-guided-storyteller"></a>
<a id="prefix-lm-non-causal-attention-on-the-prompt"></a>

## Which positions can read one another?

Suppose the input has three source positions, P1–P3, followed by four translation positions, T1–T4. P1 can read P3. P1 must never read T1, even during training when the whole translation is present in memory. If it could, an answer could leak into a source representation that later layers read.

Let $i$ be the query position, $j$ the key position, and $L_p$ the prefix length. Positions start at 1. The mask permits a pair when $j \le L_p$ **or** $j \le i$. Every row can read the entire prefix. A target row can also read its own token and earlier target tokens. A row describes the input used to predict the **next** token. [[2]](#ref-2)

<PrefixMaskFigure lang="en" />

Read the row for T1. Its four visible values come from P1, P2, P3 and T1 itself. That row predicts **T2**. To predict T1, read the output at P3, the last source position in this example. The two rows show why the diagonal belongs in the mask and why the labels shift one place.

## How GLM uses the boundary

In the original GLM blank-infilling objective, the prefix contains a damaged passage with a marker at each missing span. The target contains the missing spans in a sampled order. For example, the source can use the words on both sides of a blank, but the only missing words a target position can read are the ones supplied so far. GLM records the location of the blank and the position within its reconstruction separately. Its span markers and training targets add structure beyond the simple translation example. [[1]](#ref-1)

<a id="2-palm-parallel-sublayers-are-a-separate-design-axis"></a>

### Parallel sublayers in PaLM

PaLM computes attention and feed-forward branches in parallel inside each block. That choice changes how a layer runs. The attention mask separately determines which token positions can exchange information. [[4]](#ref-4)

## Test for a leak with PyTorch

In PyTorch's scaled dot-product attention (SDPA), a Boolean `True` makes a key visible. Passing a floating-point matrix of ones and zeros instead adds those numbers to the attention scores. A zero in that matrix leaves a forbidden key eligible for softmax. [[3]](#ref-3)

Run `python prefix_mask.py` in an environment with PyTorch installed. The CPU example uses one unpadded sequence, one head, and one scalar per position. Padding and packed examples need additional masks for valid keys and example boundaries.

<PrefixMaskExample lang="en" />

With every query and key set to zero, visible keys receive equal weight. T1 returns the mean of 1, 2, 3 and 4, which is 2.5. Raising T2 from 5 to 105 leaves T1 at **2.5** with the Boolean mask. Look at the second output line. With the float 0/1 mask, T1 jumps from **3.257** to **10.465** (rounded). The model can read a token that it is supposed to predict.

The same boundary matters when reusing a prompt cache. If a new source token becomes part of the bidirectional prefix, earlier source positions can read it. Recompute the affected prefix representations before treating them as final. Adding a target token preserves the earlier rows' visibility.

## Quizzes

<details>
<summary>Quiz 1: Why does a strictly causal mask miss information at P1?</summary>
*P1 could use P2 and P3 to interpret the source, but a strictly causal row at P1 exposes only P1.*
</details>

<details>
<summary>Quiz 2: Why can the T1 row read T1 without learning its answer in advance?</summary>
*Its label is T2. The T1 row must block T2 and later target positions.*
</details>

<details>
<summary>Quiz 3: What does the value at T1 become if all seven keys are visible in the example?</summary>
*With zero attention logits the weights would be uniform across all seven positions. Their mean is 4. With the prefix mask only the first four are visible and the mean is 2.5.*
</details>

<details>
<summary>Quiz 4: When would adding a token force you to revisit cached prefix states?</summary>
*Extending the bidirectional source opens a new key to earlier source positions. Appending a target token leaves those earlier rows unchanged.*
</details>

<details>
<summary>Quiz 5: How does GLM know which blank to fill when it generates spans out of text order?</summary>
*One position coordinate identifies the original blank and a second tracks progress within the span being generated.*
</details>
